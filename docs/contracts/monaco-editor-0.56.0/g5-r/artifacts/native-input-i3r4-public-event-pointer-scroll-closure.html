原生输入第六轮攻击：I3-R4 public event、pointer 与 scroll 闭包

本页补齐 F1-R2 未定义的 mouse/scroll adapter，并修正 I3-R3 中 public onKeyDown 被 gateway/resolver 越过的问题。I3-R3 的 local monitor、dispatch ledger 与 composition/chord 互斥结构继续有效；事件阶段顺序以本页为准。

I3-R4

public key event 必须先于 keybinding 与文字默认动作；pointer/scroll 必须只消费 V1-R4 的同一 hit-test 与 scroll state

字段快照保持 immutable；preventDefault / stopPropagation 是只在同步 callback 生命周期内有效的独立 EventControl。键盘、鼠标、滚轮、菜单、拖选和宿主 responder chain 均使用同一 dispatch record，禁止二次 resolve、二次 input 或第二套坐标。

本轮四个确定命中

31 · gateway 可先执行 resolverMonaco 输入节点先 emit public onKeyDown，事件随后才 bubble 到 StandaloneKeybindingService。I3-R3 的 state arbitration 前插入 public synchronous phase。
32 · immutable event 不需要 preventDefaultIKeyboardEvent 与 IMouseEvent 公开 preventDefault / stopPropagation。immutable payload 与 MainActor-scoped EventControl 分离，方法不可删除。
33 · F1-R2 已定义 mouse adapter它只列出域名，没有点击次数、目标类型、拖选、滚轮或菜单时序。本页给出唯一 native dataflow 与逐状态合同。
34 · NSEvent.clickCount 可直接决定选择Monaco 还用 400 ms、逻辑 position、逐级递增与 position-equal 次数再次约束 detail。AppKit clickCount 只作为输入，继续执行 Monaco clamp。

Scroll / zoom 唯一适配

Delta normalization

  • Monaco delta：precise = scrollingDeltaX/Y ÷ 40；coarse = scrollingDeltaX/Y
  • 内部位移继续执行 Monaco 常数 50：precise 每 AppKit point 位移 1.25 point；coarse 每 tick 位移 50 point
  • AppKit 正方向已与 Monaco StandardWheel 一致，且已按自然滚动偏好反向；禁止再次取反
  • 保留 Double residual；写入公开 scroll state 时才服从 V1-R3 integer contract
  • 禁止按当前 lineHeight 另建 native scroll 路径，也不读取 CGEvent device delta

Option semantics

  • mouseWheelScrollSensitivity 乘两个轴
  • scrollPredominantAxis 先择主轴
  • Option 再乘 fastScrollSensitivity
  • handle/alwaysConsume、smoothScrolling、inertialScroll 状态机保留
  • 未滚动且非 alwaysConsume 时调用 nextResponder，支持外层 scroll view

Zoom

  • mouseWheelZoom=false：scroll/magnify 交正常滚动或宿主
  • 非 precise Command-scroll：按 Monaco delta 符号每事件 ±1 zoom level
  • precise Command-scroll：accum += scrollingDeltaY÷40；level = start + accum÷5；phase=None 用 50 ms gap
  • magnify m：accum += 2.5×ln(1+m)，再执行 level = start + accum÷5；等价 Chromium NSEvent→pinch→wheel→Monaco 链
  • 所有路径将 level clamp 到 [−5,20]；Shift/Option 同时按下不触发 zoom

Hover / cursor / menu

  • NSTrackingArea inVisibleRect + activeInKeyWindow + mouseMoved
  • 每个 AppKit move 同步发 public event；只合并 renderer invalidation
  • resetCursorRects 消费唯一 MouseTarget
  • right-click 与 ctrl-left 进入同一 contextmenu contribution
  • preventDefault 禁止 NSMenu；stopPropagation 禁止 host chain

Hard traces

  • 单/双/三/四击，跨 position 与 400 ms 边界
  • Shift/Option/Command/Control × left/middle/right
  • content/gutter/zone/widget/minimap/scrollbar/outside targets
  • 拖选越四边、失焦、button mismatch、dispose
  • precise/coarse/natural/momentum/zoom/nested scroll
