辅助功能第七轮攻击：A1-R 原生文本合同闭包

F1-R 只定义 rich/plain AX，V1-R3 只定义范围几何；两页都没有定义完整 NSAccessibility 文本面、可写属性、多选与通知。本页补齐这些合同。与旧页冲突时，AX 文本与写入语义以 A1-R 为准。

A1-R

AX 不是第二份编辑器，也不是截断的 screen-reader mirror；它是同一模型、同一 NativeTextIndex、同一 ViewGraph 的同步 AppKit 投影

所有索引为 LF-normalized raw UTF-16 code unit；range/value/selection/frame 共享一套 checked map。AX 写入先进入 ModelInputBarrier，再以 R1 事务落盘。纯 Swift 通过精确 Objective-C selector 暴露 NSString，禁止 Swift String 修复孤立 surrogate。

本轮六个确定命中

35 · AX value 复用 Monaco 分页镜像Monaco 浏览器用分页 DOM 绕开 Chromium 长文本卡顿；AppKit 文本协议本身接受全文 value/range 查询。native 暴露全文 LF 投影，accessibilityPageSize 只控制 geometry materialization。
36 · Swift String 能保留 model 全域模型允许孤立 UTF-16 surrogate；Swift String 会修复。getter 用 @objc selector 返回 NSString/NSAttributedString，直接从 raw units 创建。
37 · singular selection 足够AppKit 明确提供 selectedTextRanges；本机 NSTextView 保留多 range 并排序。AX getter 暴露所有 editor selections，primary 始终排第一。
38 · AX setter 可直接改 modelsetter 会与 marked text、LSP edit、另一 editor 竞争。所有 setter 先走 model-wide ModelInputBarrier，再提交 R1 transaction。
39 · plain text 不需要 attributesSDK 明示 custom text engine 要提供 MarkedMisspelledText 才能支持 VoiceOver 拼写反馈。plain 仍返回 base font；rich 再叠 token/decorations/markers/link。
40 · model event 自动通知 VoiceOver自绘 NSView 没有 NSTextView 的自动通知。按 batch 明确 post value、selection、layout、marking 与 announcement notifications。

AX 写入、通知与 screen-reader mode

Selection setters

  • singular setter：checked LF range→model range；ModelInputBarrier；以该 range 替换全部 selections
  • multiple setter：验证每个 NSValue/NSRange；排序、merge/limit 使用 Monaco setSelections 规范化
  • 输入数组首项是 primary；规范化后 primary identity 按 editor 规则保留
  • selection-only transaction 不产生 contentVersion
  • 最终 post selectedTextChanged

Text setters

  • selectedText：执行 Monaco type replacement，一次写入所有当前 selections；结束为 primary-first collapsed selections
  • value：执行 setValue 内容 flush；单个 undo boundary 与 content-flush event；selection 按 Monaco setValue 路径恢复/裁剪
  • 输入 NSString 直接读取 UTF-16 units
  • readOnly、invalid range、dispose：selector 拒绝或 no mutation
  • 所有 edit 都走 I3-R/R1，不直写 buffer

Notifications

  • 每个 GlobalModelEventHub batch 至多一次 valueChanged
  • primary/all selection 变化至多一次 selectedTextChanged
  • projection/geometry epoch 改变时一次 layoutChanged；focus 改变由 AppKit focus notification
  • setMarked/unmark 分别 post markingSessionBegan/Ended
  • post 在 model+selection+projection 全提交后、下一批 listener 前

Announcements

  • Monaco alert/status 输出进入串行 MonaAXAnnouncementBus
  • 对 application element post announcementRequested
  • userInfo 同时含 announcement string 与 priority key
  • alert=high、status=medium；相同 batch 同文本去重
  • screenReaderAnnounceInlineSuggestion=false 时不发对应 announcement

Mode computation

  • accessibilitySupport=on→Enabled；off→Disabled；auto→NSWorkspace.shared.isVoiceOverEnabled
  • KVO voiceOverEnabled 变化同步重算 computed options 与 accessibilityModeEnabled context
  • Enabled 强制 wrappingStrategy=advanced、wrappingIndent=none
  • allowVariableFontsInAccessibilityMode 控制 effective font
  • 关闭 optimized mode 不移除 AX text surface，只关闭特定 optimized behavior

ABI 与 current status

  • Swift @objc 精确 selector 可返回 NSString 并覆写 NSView selector；本机 Swift 6.3 probe 已编译运行
  • 不需要 Objective-C source target；不扩大生产依赖
  • 仓库仍无 AX implementation/VoiceOver trace
  • C07/P13 当前未通过
  • 本页只关闭设计歧义
