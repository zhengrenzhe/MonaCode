辅助功能第八轮攻击：A1-R2 selector / attribute / action 闭包

A1-R 的 raw UTF-16、LF NativeTextIndex、全文 range、multi-selection、geometry barrier 与 notification batch 继续有效。本页修正 value setter、通用诊断属性，并补齐 placeholder、RTF、link child、show-menu 与 selector policy。冲突项以 A1-R2 为准。

A1-R2

文本 AX 面现在有完整 selector disposition；通用诊断、链接和 ghost text 不再塞进错误的属性

模型字符仍是唯一 AX text index。可见但不属于模型的语义通过 annotation、link child 或 announcement 暴露；不会为了丰富 VoiceOver 内容篡改 value 长度。所有写 selector 和 action 都有唯一允许条件、状态变化与通知结果。

本轮八个确定命中

41 · setValue 形成一个 undo boundary锁定源码直接 clear command manager、decorations 并发 Flush。它清空 undo/redo；不是可撤销 edit。
42 · 所有红色 squiggle 都是拼写错误MarkerData 没有标准 spelling identity。通用 marker 使用 AXAnnotation；不伪造 MarkedMisspelled。
43 · AXLink 可直接存 URLSDK 要求对应 UI element；NSTextView 实测返回 AXUIElement，且 children 中存在 AXLink。建立 MonaAXTextLink child。
44 · attributed string 已覆盖所有文本 selector协议还列出 RTFForRange。全局范围已排除 RTF/RTFD；该 selector 显式拒绝并返回 nil。
45 · context menu 只有鼠标入口NSAccessibilityProtocol 提供 performShowMenu。复用 I3-R4 同一菜单 action path。
46 · placeholder 只影响像素AppKit 提供 accessibilityPlaceholderValue。直接映射 retained placeholder option。
47 · AXTextCompletion 可贴在任意前缀本机 probe 证明该 key 的值是 Boolean，且标记实际存在于 attributed characters。ghost text 不在 raw value 中，因此不误贴；继续走 Monaco announcement。
48 · selector 存在就全部可调用readOnly、dispose、无 model、contextmenu=false 与显式 RTF cut 有不同许可。isAccessibilitySelectorAllowed 逐 selector 判定。

写 selector 的精确事务结果

selectedText

  • 读取输入 NSString raw UTF-16
  • 结束 composition 后执行 Monaco type across all current selections
  • 每个 surviving selection 结束为 insertion caret
  • merge/limit/orientation 服从 CursorCollection normalize
  • 一次 R1 content transaction；保留正常 undo/redo

value

  • 调用 model setValue-equivalent flush，不伪装 executeEdits
  • 清空 model undo/redo、tracked decorations 与 trim state
  • 版本递增并发一次 content Flush
  • 所有 attached editors 因 Flush 重建 cursor；发起 editor 随后设单 caret 到新全文末端，以匹配 NSTextView AX setter
  • 同一 barrier 合并为一次 value 与一次 selected-text notification

Selections

  • singular setter 清除 secondary selections
  • multiple setter 首项作为 primary；超 multiCursorLimit 截取前 N
  • CursorCollection 用临时位置排序做 overlap merge，最终 cursor array 保持 primary-first
  • primary 与其余稳定次序直接决定 getter
  • selection-only mutation 不改 content version

C07 / P13 修订 fixture

Setter state

  • setValue 前后 undo/redo、decorations、versions、Flush
  • active editor caret=end；shared second editor caret=start
  • selectedText 多光标 undo round-trip
  • readOnly/dispose/invalid selector zero mutation

Attributed output

  • base/rich style run exact
  • overlap diagnostics become AXAnnotation arrays
  • generic markers never become MarkedMisspelled
  • ghost text never changes AX length/range

Links/actions

  • AXLink child identity/range/frame/label
  • provider refresh/edit/dispose invalidation
  • press success/rejection and host opener trace
  • show-menu on/offscreen/readOnly/contextmenu=false
事实索引：Monaco 0.56.0 TextModel._setValueFromTextBuffer 直接销毁 decorations、clear command manager 并发 RawContentChangedType.Flush；Cursor 收到 Flush 后重建 CursorCollection。MacOSX26.5.sdk NSAccessibilityProtocol 明列 placeholder、RTFForRange、performShowMenu、selector policy、AXAnnotation/Link/MarkedMisspelled/TextCompletion keys。当前设备 NSTextView probe 验证：AX value setter 将 caret 放到新值末端；AX attributed output 把 direct annotation 保留为 AXAnnotation、direct marked-spelling 保留为 Boolean、TextCompletion 保留为 Boolean、link 转为 AXUIElement；accessibilityChildren 同时产生 NSAccessibilityTextLink，role=AXLink、label=range substring、frame=range screen frame；RTFForRange 会生成 NSData。全局范围已明确排除 RTF/RTFD，因此 MonaCode 对该单项采取显式 cut。当前仍无产品 AX implementation 或 VoiceOver trace。
