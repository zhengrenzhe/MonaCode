正式 npm tarball 是行为基线；commit metadata 只作来源线索

产品差分一律运行 monaco-editor@0.56.0 正式包。源码移植一律引用 monaco-editor-core@0.56.0 正式 tarball及逐文件 hash。无法由公开 commit 重建的字段不再进入等价声明。
