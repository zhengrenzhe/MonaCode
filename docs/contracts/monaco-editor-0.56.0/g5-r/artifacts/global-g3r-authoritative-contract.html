MonaCode 全量目标：G3-R 唯一权威合同候选

本页替代 G1-R 与 G2-R，只冻结全量功能集合、明确裁剪、原生适配、架构状态机、事实基线与验收门槛。它不划分阶段，也不把设计完成写成产品通过。

G3-R

全量功能范围已经机器闭合；实现与实测仍为零

本期交付 arm64 macOS 26.0+ 原生 Swift 编辑器组件。文本与公共行为按 Monaco Editor 0.56.0 正式 npm 产物对标；布局使用同步 Projection + Core Text；Core Graphics first，只有 renderer-owned gate 失败才触发 Metal；语言基础设施全量、生产语言实现为 0；性能在同一环境 cell 内必须同时不劣于 M0 official 与 M1 matched。

G2-R 与 G3 自审命中的九个确定错误

61 · 章节停在旧 revisionG2 仍指 M1/L2-R2/I3-R/F1/Q1-R2。G3 固定 M1-R2、L2-R3、I3-R4、F1-R3、Q1-R4。
62 · 缺少整个规范域G2 未列 B1、T1、P1、A1/A2。G3 纳入 base、theme、provenance 与完整 AX 合同。
63 · dev core 仍被当正式基线P1-R 已证明正式依赖是 core 0.56.0。G3 固定 final core tar SHA-256 78e222c7…96f4ed。
64 · 外接屏历史被写进 deployment当前本机只有内建 Liquid Retina XDR。60/120 Hz 是同一内建面板两个 cell；每次运行重采 QEnvironmentID。
65 · 4 个 editor key 被误写成 cutmanifest 显示 colorize×3 与 multi-diff 是 native replacement。editor 68 = 63 mapping + 4 replacement + 1 WebWorker cut。
66 · A2 只按 widget 总数验收旧 A2 漏映射 25 个 retained feature。A2-R2 逐项覆盖 64 feature、24 contracts、8 focus modes。
67 · 29 个公告点无逐项证明源码实际有 39 个 pattern。逐项归类后是 30 effective + 9 excluded；空消息不发声。
68 · “最终页”自身没有完整性证明旧页只用 prose 指向历史页。G3 manifest 固定 28 个规范层 + 3 个机器工件及全部 SHA-256。
69 · 实例 API 只有 133/55 总数旧 F1 没有冻结重载、继承和成员顺序。独立 d.ts manifest 逐项锁定 5 个接口；实例成员零裁剪。

不再重开的决定

Architecture locked

  • 无 TextKit production 或 editable mirror
  • Core Text 是唯一 typography truth
  • CG first；Metal 只由 renderer gate 触发
  • 无 runtime renderer selector
  • 无第三方 production runtime

Language and product cuts

  • 本期语言实现为 0，保留 plaintext metadata
  • LSP client 是核心；server/transport 由 host 提供
  • 11 个 option cut 与 namespace cut 从 Swift surface 删除
  • audio signals/Accessible View 按 standalone inert 基线不新增
  • iOS/iPadOS 只作为 later，不混入本期 gate

Authority and licensing

  • hash mismatch 立即使 G3 无效
  • source/SDK/spec 反例必须新建 revision
  • Monaco code 保留 MIT notice
  • Codicon artwork/font 按 CC BY 4.0；Git Logo 例外按 CC BY 3.0；code/generator 按 MIT
  • 实际分发的测试、规范、资产保留对应 notices
