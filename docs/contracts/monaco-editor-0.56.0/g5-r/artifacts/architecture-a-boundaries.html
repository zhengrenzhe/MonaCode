同步输入热路径

NSEvent / IME› Input Controller› Command› EditTransaction› MonaModel› Range invalidation› Viewport layout› Display
TextKit 风险隔离点：Custom NSTextContentManager 只按需产出 paragraph elements；若超长行、Decoration 或 viewport 基准不达标，只替换 Render Backend，不增加第二份可编辑文本。

不可破坏的规则

  1. 只有 MonaModel 能修改文本。
  2. TextKit 编辑回调必须转换为 EditTransaction。
  3. 后台任务只能读取 immutable snapshot。
  4. 异步结果携带 model version，过期即丢弃或显式 remap。
  5. 一个 Model 可绑定多个 Editor；View State 不写入 Model。
  6. 平台层不得泄漏到公共 Model/Provider API。
