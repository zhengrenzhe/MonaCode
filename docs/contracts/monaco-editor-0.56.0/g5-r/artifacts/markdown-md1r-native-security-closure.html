渲染与安全补漏攻击：MD1-R 原生 Markdown 闭包

官方 public surface 保留 IMarkdownString 与 11 个 provider/editor consumer fields。G4 此前只写“hover markdown”，没有冻结解析、信任、command link、raw HTML、媒体副作用、code block 与 AX 语义。

MD1-R

保留完整非 HTML Markdown；Swift 直接生成语义树，绝不生成或执行 Web 内容

固定 Marked 14.0.0 同步 GFM grammar。supportHtml 从 Swift API 显式删除；图片/媒体只保留 alt text，不加载任何字节。普通链接走双 opener，可信 command link 走现有 command route。

四个攻击命中

113 · Markdown 是普通字符串public value 还携带 trust、theme icons、baseUri 与 URI map。冻结 MonaMarkdownString 值语义与 11 个入口。
114 · supportHtml 可继续保留完整路径依赖 HTML fragment parser、67-entry tag policy 与 DOM sanitizer。从 Swift API 显式 member-cut；默认 false 语义继续。
115 · 链接都交给 opener可信 command URI 实际经过 allowlist 与 command service。普通链接走 opener；command 走 registry→host。
116 · 图片只是排版细节浏览器路径会读 data/file/http bytes。媒体加载/播放明确 cut；只保留 parsed alt text，零外部副作用。

唯一数据流

Side effects普通 link→MonaLinkOpener；command→registry/host；media=none。
