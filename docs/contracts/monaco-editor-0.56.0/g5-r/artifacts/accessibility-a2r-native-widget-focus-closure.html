辅助功能第十轮攻击：A2-R2 原生控件、Widget、焦点与 Feature 闭包

A1-R2 继续定义编辑器文本 AX surface。本页从锁定的 editor.main.js 静态导入闭包出发，补齐原生控件、隐式 HTML 语义、复合焦点、公告、canvas action proxy、宿主 widget、普通/多文件 diff，并逐项处置 F1-R3 的 64 个 feature entry。与旧页冲突时，A2-R2 widget 语义以本页链接的 JSON 为准。

A2-R2

控件层收敛为 24 份 widget contract、8 种焦点模式、64 项 feature 处置与一个主线程 AX barrier

可直接使用 AppKit 的控件全部使用真实原生控件；canvas 中只有可执行的可见项建立稳定 NSAccessibilityElement proxy；纯视觉 surface 保持隐藏。语言包裁剪不改变 UI/LSP provider 的 AX 合同。当前仅形成设计基线，没有原生产品实现或通过记录。

本轮十二个确定命中

49 · editor.api 不是运行时闭包从它出发只能到 642 个 JS，漏掉绝大多数 contribution。唯一入口改为 editor.main.js：1,135 个。
50 · 只扫 ARIA 会漏 Inspect Tokens该 widget 使用原生 h2 + table 语义，无显式 role。新增 semantic-element scan 与 AXHeading/AXTable。
51 · Multi-file diff 属于公开 APIeditor.createMultiFileDiffEditor 位于 d.ts 与 runtime namespace。折叠标题、资源、状态与子 diff 全部进入 A2。
52 · view zone 宿主内容可见源码父容器明确 role=presentation 且 aria-hidden=true。原生 view-zone 与 margin 子树整体隐藏。
53 · content/overlay widget 同样隐藏两个容器没有 aria-hidden。宿主 NSView AX subtree 必须原样保留。
54 · Suggest 要把焦点移入列表Monaco 使用 editor input 的 active-descendant；编辑器继续收键。采用 accessibilitySharedFocusElements，不转 first responder。
55 · 参数提示上下箭头无需角色源码按钮只是可点击 div，没有 ARIA role。原生 NSButton 补齐角色，但保持 editor-shared 状态机。
56 · Audio signal 是本期缺口standalone playSignal 函数体为空，包中音频资产数为 0。这是误报；A2 明确不新增音频面。
57 · Accessible View 注册即有效provider registry 可达，但 standalone 没注册两个入口 action。registry-only 路径是 inert，不进入产品范围。
58 · 所有 status 调用都会播报39 个词法命中包含 2 个函数声明、1 个方法声明、5 个 notification no-op 与 1 个配置不可达点。30 个有效点进入 oracle，9 个必须无输出。
59 · Widget 清单等于 Feature 闭包旧版只映射 37 个 feature ID，还混入并非 feature entry 的 minimap。现逐项处置 64 项：62 macOS、1 iPadOS later、1 cut。
60 · 无控件目录等于无 AX 合同readOnlyMessage 复用 MessageController；unusualLineTerminators 通过 StandaloneDialogService 调用 confirm。新增消息与原生 modal dialog 两份合同。

八种焦点模式

Editor sharedfirstResponder = editorSuggest、参数提示、rename candidate 与 inline 控件使用 shared focus；键入永远送进同一个编辑事务入口。
Owned inputfirstResponder = fieldFind、replace、rename、quick input 的 NSTextField 独占输入/IME；commit/cancel 只恢复一次捕获的 editor token。
Owned collectionfirstResponder = list/treeAction widget、references、accessible diff 使用 collection 的上下/展开/选择/退出状态机。
Explicit popoverfocus on explicit entryHover、color、banner 仅在键盘命令、VoiceOver entry 或直接控件激活时夺取焦点；鼠标显示不夺取。
Native controlfirstResponder = control按钮、菜单、链接、popup、slider 与 color well 使用 AppKit 标准键盘行为；terminal action 后只恢复一次 owner。
Modal dialogfirstResponder = alert sheet异常换行符 sheet 独占 editor 交互；resolution 重验 editor/model/version/generation/dialog identity。
Host ownedfirstResponder = host NSViewcontent/overlay widget 的内部 key loop 由宿主拥有；移除时保留有效 owner，失效时恢复 editor。
Passiveno AX / no tab stopMinimap、ruler、margin、view zone、纯 decoration、视觉 folding glyph 保持隐藏；操作由 retained command 提供。

24 份 widget contract

输入与候选

  • main-text-surface：完全引用 A1-R2
  • suggest：Suggestion list + resolved docs
  • quick-input/tree：label/detail/check/level/count/busy
  • find-replace：dialog controls + match announcement
  • rename：input + shared candidate list + generation

语言/LSP UI

  • action-widget：code action、paste/drop alternate edit、format
  • hover：markdown、marker、link、copy、verbosity
  • parameter-hints：active parameter 去重公告
  • diagnostics：severity/message/source/code/related
  • references：outline + preview + exact ariaMessage

注入与 canvas action

  • codelens：visible AXButton proxy
  • inlay/inline：annotation + actionable proxy
  • color-picker：NSColorWell/NSColorPanel replacement
  • sticky-scroll：visible AXList rows
  • unicode-banner：group + actions
  • post-edit/progress：button proxy + action widget

Diff 与开发者面

  • diff-editor：两 text areas + hidden region buttons + AXList viewer
  • multi-file-diff：public native replacement + disclosure groups
  • inspect-tokens：AXHeading + AXTable

平台与宿主

  • menus/toolbars/primitives：NSMenu 与真实控件
  • host content/overlay：原样保留 NSView AX subtree
  • read-only-message：alert + read-only text/link
  • unusual-line dialog：NSAlert sheet + stale revalidation
  • hidden rendering：view-zone/margin/glyph/minimap 等整体缺席

统一不变量

  • UI label 复用相同 formatter，不复制字符串逻辑
  • async request generation 不匹配时零公告、零焦点变更
  • AX press 重验 model/item/precondition/enabled
  • frame-only layout 不替换 proxy identity
  • 大文档不建立 per-line AX object graph
