本轮确定的九个旧结论错误

125 · 1054 全是 JSside-effect import 把 98 个 CSS 纳入了旧计数。规范改为 956 JS + 98 style，总数仍为 1054。
126 · performance 只在 Tree-sitter13 个 retained StopWatch 使用 high-resolution clock；输入延迟另有 25 个 Performance API 调用。固定为 mach_absolute_time 域。
127 · raw UTF-16 永不替换model truth 不替换，但 StringBuilder/TextDecoder 会把孤立 surrogate 变成 U+FFFD，并吞掉开头 U+FEFF。替换点按 utility 隔离。
128 · CSS compatibility cut 等于样式 cut98 个 sheet 仍编码 widget geometry、focus、motion 与 visibility。CSS runtime 不存在，但 retained rule 必须映射 native state。
129 · 每个 CSS variable 都有值257 个引用名中有 17 个固定 standalone 无 provider、无 fallback；对应 48 个声明在 Chrome 基线中 inactive。native 不得擅自补圆角、阴影或颜色。
130 · static CSS 就是完整视觉面源码另有 73 个 runtime rule-construction sites、14 个 theming registrations 和 724 个 inline style assignments。全部进入逐行 native effect closure。
131 · editor.main closure 等于 npm 包固定包有 2112 files / 1008 JS；vs 下 994 JS 中 38 个不在入口闭包，另有 14 个 NLS tables。38 个逐文件排除，14 个归 N1 数据所有。
132 · 无 fetch 就等于无外部 effect源码还有 window open/location、Markdown src/href、worker object URL 与 browser-location read。14 个隐式位点逐项归 H1、MD1、worker cut、N1/E1 或纯 parser value。
133 · URI icon 路径要求新增 loader10 个 asCSSUrl 位点存在，但固定 standalone 的 retained URI-backed producer=0；121 个 menu rows 只有 ThemeIcon/undefined。保持 inert，不增加第 8 个 host group。
