A+ 的提交、有效性与恢复契约

目标：同步模型语义不打折；后台任务不触碰 live state；任何失败都只能影响自己的边界。

A+

所有 live mutation 只有一个入口：MainActor EditTransaction

公开 ITextModel 风格 API 在 MainActor 同步执行；后台调用方提交 Sendable EditIntent。模型提交结束后才投递事件，监听器异常不回滚已经提交的文本。

1 · EditIntentmodel instance、可选 baseVersion、operations、source、undo group
2 · PreflightMonaco 范围归一化、EOL 归一化、重叠检查、反向 edits、事件草案；零 mutation
3 · CommitPiece Tree、line index、Decoration Tree、undo stack、版本；不调用外部代码
4 · Event batch不可变 payload；同一 delivery queue 完成旧版本全部 listener 后再投递重入事件
5 · Invalidate取消失效请求、标记 layout/diff 重算、异步回包仍须过 MainActor gate

文本事务的确定规则

以 Monaco 0.56 本地源码为行为基线

版本不简化成“一事务一次”

  • 非空 text batch：versionId +1；空 batch 不变
  • EOL 真正变化：versionId +1；setValue：+1
  • undo/redo 同时恢复 text 与 EOL 时保留 Monaco 的实际增量与合并事件
  • alternativeVersionId 在 undo/redo 后恢复栈中记录值

失败发生在 mutation 之前

  • 范围按 Monaco 规则校验与夹取
  • 相接 ranges 合法；真正重叠直接拒绝
  • baseVersion 仅用于异步/edit-producing 路径
  • preflight 任一失败：typed error、版本不变、无事件

跨模型文本事务

  • 先 preflight 全部目标模型，再提交全部模型
  • 全部模型完成 mutation 后才按输入顺序投递事件
  • 一个 shared undo element 覆盖整次 workspace text edit
  • 任一 open model 版本不符：整批不执行

故障恢复状态机

不会把 LSP、TextKit 或 Provider 故障升级成 model corruption

LSP session

stopped›starting›initializing›ready›restarting›suspended
  • 意外退出：session epoch +1，取消 pending requests，清除 session-owned transient UI 与 diagnostics，立即退化 pure text
  • 滚动 180 秒内前 4 次 crash 自动重建 transport；第 5 次进入 suspended
  • 显式 host/user restart 清空 crash window 并创建新 session；正常 shutdown 不计 crash

Layout + Render backend

healthy›discard graph›rebuild latest snapshot›next backend
  • 版本缺口或乱序结果：只丢该 editor graph，从最新 snapshot 重建
  • 同一 snapshot 的一次完整重建仍失败：该 editor 切换下一后端
  • model、undo、其他 editor graph 不受影响

失败隔离表

stale / cancellation

静默丢弃；连续型功能重发，瞬时 UI 关闭。不向用户展示 ContentModified。

Provider / transport error

结束对应请求与 UI，记录结构化 error；live model、selection 与 undo 不变。

validation / version conflict

返回明确 action failure；workspace/applyEdit 填 applied=false、failureReason 与 failedChange。

core invariant violation

测试与 Debug 直接失败并输出复现数据。Release 不执行猜测性回滚；损坏 model 不继续接受 mutation。

WorkspaceEdit capability 不虚报：core 对全部 open models 提供原子 text transaction。涉及 closed files 或 create/rename/delete 时，只按 host WorkspaceResourceTransaction 明确担保的等级广告：全资源原子才报 transactional；全体文本资源原子才报 textOnlyTransactional；否则报 abort。第一方与第三方 host 使用同一 capability contract。
证据边界：Monaco 0.56 本地源码显示 applyEdits 在非空 change 时递增版本、拒绝 overlapping ranges、延迟合并 content event，并隔离 listener/view-model 异常。LSP 3.18 规定旧结果可在转换后继续使用、诊断 version 可省略、TextDocumentEdit edits 不得重叠，并给出 5 crashes / 180 seconds 的 VS Code 防重启风暴规则。
