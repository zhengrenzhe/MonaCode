验收协议第七轮攻击：Q1-R2 公平测量合同

Q1-R 的 C01–C08、P00–P13 与“每项不得劣于 Monaco”门槛保持不变；本页补齐双基线、空宿主扣除、共享内存、thermal、呈现观察和 corpus identity。冲突时以 Q1-R2 为准。

Q1-R2

MonaCode 必须分别不劣于官方原版 M0 与能力匹配 M1；总成本和组件增量都通过

所有 lower-is-better 指标分别计算 N/M0 与 N/M1；每个 ratio 的 paired bootstrap 95% CI 上界均 ≤1.00。任一 workload、metric、refresh-rate、baseline 失败即整体验收未通过。

本轮命中的十二个测量漏洞

01 · 官方 bundle 是唯一公平基线它携带首期删除的语言内容。M0 保证原版不劣；M1 保证能力匹配公平性；两者都过。
02 · 只测能力匹配版这无法兑现“不比原版 Monaco 差”。M0 未裁剪 editor.main 是独立硬门槛。
03 · 总进程树体现组件效率Chrome browser/GPU 固定成本可遮住 Monaco 编辑器增量。总成本与 active−ownIdle 都单独判定。
04 · 多 PID footprint 直接求和共享映射和 IOSurface 会重复记账。一次 footprint 读取整棵 targetChildren，使用去重总量。
05 · 起止 thermal nominal 足够中间 serious/critical 会改变频率。每秒采样；pair 内任一点非 nominal 即无效。
06 · ScreenCapture 帧都代表呈现observer queue 会丢帧，帧也有 idle/incomplete 状态。只收 complete + DisplayTime；drop/backlog/marker 解码失败整 pair 无效。
07 · energy impact 等于焦耳powermetrics process energy 是相对影响指标，系统 CPU/GPU power 也是估算值。分别命名 process energy impact 与 estimated SoC energy integral，只做同机配对比。
08 · 权限不足时跳过指标跳过会制造假通过。Screen Recording 或 privileged collector 不可用时，gate 保持未通过。
09 · 无效样本无限重跑这允许挑选稳定样本。每 condition 尝试数上限为所需有效数的 2 倍；不足即失败。
10 · 负 component delta 取零clamp 改写观测值。active−idle<0 的 pair 无效；不截断、不取绝对值。
11 · geometry 与 Chrome 零像素差V1-R4 已证明 shaping engine 不同。只对 exact domain 零差分；native geometry 验不变量与 CG/Metal parity。
12 · 任意随机 corpus 可复现只记录 seed 不固定 palette/PRF/encoding。Q1CorpusGenerator v1 与每个输出 hash 是运行前置条件。

Q1-2026-08-13 的三个产品身份

M0 · literal official Monaco

monaco-editor@0.56.0/min/vs/editor/editor.main，生产模式，默认 DOM renderer；npm tar SHA-256 b74bc443…fb7412。官方语言内容与 side effects 不裁剪。该基线回答“是否不劣于原版”。

M1 · capability-matched Monaco

从同一官方 ESM 包构建：62 个当前 macOS feature entry、必要 core side effects、保留的 public/LSP exports；删除 WebGPU debug、81 个 language definitions 与 4 个 language feature packs。esbuild 0.25.9；lock SHA-256 166a192d…efe9b。

N · MonaCode release

arm64 macOS 26 release optimized sample；相同 host dimensions、fonts、theme、text/options、fixtures 与外部 event trace。CG-first；Metal 仅按 V1-R4 renderer trigger 建成后替换 N renderer。

基线与 corpus 前置条件

M0/M1 manifest

  • 固定 Monaco tar、source tag、Chrome binary、V8、M0 resources
  • M1 固定入口清单、esbuild 版本、package.json/lock hash
  • M1 构建后先记录所有 output SHA-256，再开始任何 run
  • M0 与 M1 均使用 fresh temporary Chrome profile
  • manifest 任一字段变化创建新 baseline revision

Q1CorpusGenerator v1

  • namespace=MonaCode-Q1-2026-08-13
  • PRF block=SHA256(namespace UTF8 || 00 || seed u64be || counter u64be || block u32be)
  • 无偏 rejection sampling 选择 checked-in literal sequence/operation palettes
  • 覆盖 ASCII、CJK、Arabic/bidi、combining、emoji ZWJ/RI、tabs、LF/CRLF、孤立 surrogates
  • raw document 无 BOM .u16le；每个 output 与 event trace 记录 SHA-256

Artifact rule

  • generator source、literal palette、seed list、output hashes、trace hashes进入签名 manifest
  • 任何 baseline run 只读这些已哈希 artifact
  • generator/palette/trace 变更创建新 corpus revision
  • 当前仓库不存在这些 artifact
  • 因此当前所有 baseline run 均无效，状态仍为未通过

采样、统计与失败语义

Ordering

  • 每 block 含 M0、M1、N；ABC/BCA/CAB/ACB/CBA/BAC 六顺序均衡循环
  • 每产品 empty-host idle 与 active 次序交替
  • system power 每个 active 紧邻一个 neutral-machine-idle；前/后位置交替
  • cold 50 个有效 block；hot/resource 各 30 个有效 block
  • 每 condition 最多尝试所需有效数的 2 倍

Verdict math

  • latency/present/miss 直接比较，不减 idle；资源同时比较 total 与 component
  • 每 run 先算 p50/p95/p99 或单位工作 cost；对 paired ratio 做 10,000 次 bootstrap
  • N/M0 与 N/M1 的 95% CI 上界分别 ≤1.00
  • comparator 连续值≤测量分辨率时，改用 paired difference CI 上界≤0
  • 离散 comparator=0 时 N 所有有效样本也必须=0

Invalid / fail

  • 不删除 outlier；保留原始 trace
  • 无效样本只按固定 attempt cap 补齐
  • 样本不足、manifest/hash/权限不符直接失败
  • 任一 correctness mismatch、CI 跨 1、复杂度更差直接失败
  • 综合分、跨 metric 抵消与事后改门槛全部禁止

Reliability

  • 1,000 lifecycle cycles；24h P02–P13 soak
  • Leaks definite=0；Main Thread Checker=0
  • ASan、TSan、UBSan 分开运行且 finding=0
  • CG-only：Metal validation=N/A；Metal built：finding=0
  • crash、hang、data loss、half commit=0

Metal trigger

  • 仅 first/input-present、missed presentation
  • 仅 frame CPU/GPU、renderer energy impact/footprint
  • 这些指标任一失败进入 Metal implementation
  • 其他失败只修所属子系统
  • Metal 完成后重跑 C01–C08/P00–P13/reliability

Current status

  • 仓库没有 production source/executable
  • M1 output、corpus、controller 与 collector artifact 均不存在
  • C01–C08、P00–P13、reliability 全部未执行
  • 正确性与性能状态统一为“未通过”
  • 设计合同收敛不改变实测状态
唯一允许的发布结论
“MonaCode revision X 在 Q1-2026-08-13 的固定 artifact manifest 上通过 C01–C08；对 M0 官方原版与 M1 能力匹配版，在 P00–P13 每个共同 metric 的 total cost 与 component cost 上，N/comparator 配对比值 95% CI 上界均不超过 1.00；复杂度不高于 Monaco 0.56.0。”
