完整功能面第五轮攻击：F1-R 封闭合同

“完整复刻”被定义成一个有限且可机器核对的集合：官方包哈希、feature/action/contribution/command/keybinding/menu 注册表、options、Diff 与公共 editor surface；JS/DOM 源兼容不在目标内。

F1-R

功能不按 UI 截图猜测；以注册表、公共接口和运行时清单为唯一范围

所有保留项必须有实现、默认值、更新语义、事件、命令/上下文前置条件和差分用例。所有删除项在 Swift API 中不存在并有迁移替代；禁止“接受参数但不产生语义”的静默 no-op。

本轮命中的十二个反例

01 · 64 个目录等于全部 APIfeature 目录不含 ITextModel、editor/diff methods、options、widgets、themes、markers、commands。F1-R 同时冻结注册入口、public surface 与运行时 manifest。
02 · 174 项全部直接照搬其中含 DOM、CSS class、EditContext、Linux-only、WebGPU/SVG backend switch、V8 locale segmenter 和 computed-only 值。157 个 retained input、6 个 native computed-only、11 个 explicit cut，逐名列出。
03 · 127 supported actions 是全局 action 表该 API 会调用 `isSupported()`，无 provider 时过滤 rename/reference/format 等动作。官方全表 167，native target 166；127/126 分别只是官方/native 纯文本 oracle。
04 · Diff 只有左右两栏公开面含 inline、unchanged region、move、accessible viewer、revert、breadcrumbs 和算法选择。UI/事件/options 全纳入；算法值单独定性。
05 · external diff 更先进就保留0.56 动态导入 `@vscode/diff`；adapter 固定 ignoreTrimWhitespace=true，max time 在该 adapter 中未实现。只移植 legacy/advanced；external/wasm 从 Swift enum 删除。
06 · NSUndoManager 保存编辑历史AppKit grouping/target 生命周期不等于 Monaco model undo stack。MonaCodeModel 是唯一历史真相；undo:/redo: 只是 responder-chain facade。
07 · SwiftUI 可承载编辑热路径输入协议、命中、拖放、菜单、AX、刷新同步都落在 NSView/NSTextInputClient。SwiftUI 只包装 MonaCodeEditorView，不持有 model/view state。
08 · 完整组件等于 Workbench文件树、扩展宿主、窗口、SCM、终端不属于 Monaco Editor 组件。只提供 opener/workspace-edit/command/LSP/logging host protocol，不取得宿主所有权。
09 · 64 feature entrypoints 覆盖全部副作用editor.main 还单独导入 coreCommands、controller 和 standalone strings；main 比 modular 组合多 4 actions、2 contributions、6 commands、2 keybindings。注册表 oracle 固定 editor.main。
11 · experimental renderer option 可原样保留`experimentalGpuAcceleration` 只切 DOM/WebGPU；`experimentalWhitespaceRendering` 只切 SVG/font/旧 DOM。二者删除；`renderWhitespace` 保留可见语义，CG/Metal 只由 V1-R4/Q1-R2 gate 选择。
12 · Apple 分词器可等价替代 Intl.Segmenter非空 `wordSegmenterLocales` 由 V8 `Intl.Segmenter` 产生 locale-sensitive boundary，并进入移动、选择、删除与 word lookup。该非默认 option 删除；默认空数组继续逐代码移植 `wordSeparators` 路径。

Diff、宿主边界与 API 等价级别

Diff 完整面

  • side-by-side、inline、true-inline、responsive breakpoint
  • line/char changes、moves、unchanged regions、overview、breadcrumbs
  • revert、originalEditable、accessible diff viewer、save/restore view state
  • single Diff 与 public Multi-File Diff 都保留
  • legacy/advanced 逐代码移植；external/wasm 不在 Swift enum

Host protocols

  • MonaResourceOpener：URI/definition/link
  • MonaWorkspaceEditApplier：跨 model R1 transaction
  • MonaCommandHost：provider command 与宿主 command
  • MonaLSPProcessProvider / MonaMessageTransport
  • MonaLogSink；无文件系统、网络、窗口、扩展宿主所有权

Public equivalence

  • ITextModel：M1-R 逐 API 可观察语义等价
  • ICodeEditor/IDiffEditor：methods、events、state machine、widgets、zones 与操作意图等价
  • 返回 pixel/coordinate/size/scroll extent 的 API 保留，但数值属于 V1-R4 Core Text native geometry domain
  • Position/Range/Selection/URI/Marker/Theme/ContextKey/Keybinding 等值语义
  • HTMLElement→NSView protocol；Promise→async；IDisposable→MonaDisposable；JS/DOM source compatibility 删除

Native ownership / AX

  • MonaCodeEditorView: NSView + NSTextInputClient 是热路径唯一 view
  • SwiftUI Representable 只做生命周期与 binding 桥接
  • MonaCodeModel 是 undo/redo 唯一真相；NSUndoManager 不保存历史
  • `renderRichScreenReaderContent=false`：AX range 暴露 plain text；true：`accessibilityAttributedStringForRange` 从 token/decoration runs 生成 AppKit AX font/color/underline 等属性
  • `find.globalFindClipboard` 映射 macOS find pasteboard；Linux `selectionClipboard` 仍删除；widgets/zones 使用 typed NSView API

Theme / icon / style

  • vs、vs-dark、hc-black、hc-light 默认 token/theme 语义
  • 自定义 theme、semantic token rules、editor colors
  • Codicon TTF `cc2472e2…a8` 与 glyph map 随组件分发
  • Monaco 代码/翻译保留 MIT notice；Codicon 图标内容保留 CC BY 4.0 attribution、license URI 与 modification notice
  • CSS class decoration 字段转换成 typed MonaDecorationStyle

Package boundary

  • MonaCode, Base, Model, EditorCore, Language, LSP
  • Features, Diff（含 MultiDiff）, Theme, AppKit, SwiftUI
  • CoreText/CoreGraphics/Metal 是 renderer internal，不导出 backend API
  • Conformance/TestKit/Benchmark 只存在于仓库测试产品
  • 生产 linked code 只依赖 Apple system frameworks；Codicon TTF 是随包许可资源，不是 linked runtime
