Standalone 服务补漏攻击：S1-R 会话状态与反馈闭包

从固定 editor.main.js 递归静态闭包出发，逐一处理 40 个默认服务。结论不是“平台服务由 AppKit 代替”，而是每项都固定为保留、原生适配、host、进程内状态、空实现或显式裁剪。

S1-R

进程内状态全部保留；磁盘持久化、遥测、额外通知与进度 UI 全部禁止

14 个 storage consumers 共享 eager InMemoryStorageService。它跨 editor disposal 存活、跨 process 不存活。4 个 dialog call sites 映射为 AppKit sheet；notification、progress、telemetry 与 accessibility signal 保留 fixed standalone 的日志或空输出语义。

固定事实

956reachable JS另有 98 个 imported style resources；总计 1054 files。
40default services全部有唯一 disposition。
14storage consumersfind、suggest、peek、quick input、menu、CodeLens。
22key identities仅进程内；无 disk/defaults/keychain/host。
4dialog sitesunusual line、workspace undo、undo confirm、command error。
0shutdown flush callersCodeLens/command MRU 的 shutdown storage path 不可达。

四个攻击命中

117 · Editor dispose 后状态清空fixed service 是 process eager singleton。find/history/widget/peek/quick state 跨 editor 存活，只有 process restart 清空。
118 · 原生版顺手持久化四个 baseline scope 都使用 InMemoryStorageDatabase。UserDefaults、Keychain、文件、数据库、网络与 host storage 全禁。
119 · 只有 unusual-line dialogsource closure 还有 3 个 call sites。补入 workspace undo、undo confirmation 与 command error。
120 · 通知/进度可升级为 native UIstandalone prompt/status/progress/telemetry/signal 是 no-op。新增 toast、spinner、遥测、音频都属于范围扩大并被禁止。

会话状态合同

Find

  • 4 个 bool flags，default=false
  • find / replace history insertion-ordered unique
  • 源码没有 eviction bound
  • 跨 editor，共享 workspace namespace

Suggest

  • first / recentlyUsed / prefix
  • LRU 300；prefix serialized 200
  • 500 ms save scheduler
  • widget size 2 identities + docs flag

Quick / Peek / Inline

  • quick input view state
  • goto zero-based flag
  • command MRU runtime bound 50
  • Peek layout、snooze 300000 ms、new-user kind

Inert persistence paths

  • shutdown flush caller=0
  • CodeLens cache2 never saved
  • commandPalette MRU keys never saved
  • live caches still retain in-process behavior
