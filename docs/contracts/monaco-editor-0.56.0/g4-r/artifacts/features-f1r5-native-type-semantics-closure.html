公共类型第六轮攻击：F1-R5 native type semantics 闭包

F1-R4 已枚举 555 个公开声明路径，但未把 TypeScript 标准容器、null/undefined、any/unknown 与 provider 调度映射成唯一 Swift 语义。本页依据同一 d.ts AST、Monaco consumer 源码和 Chrome 151 探针封闭该层。

F1-R5

434 个 retained path 不变；新增一条 Monarch member cut；Swift 容器不再依赖 Array/Dictionary/Optional 的默认语义

公共 Swift canonical types 保留 source 能观察到的 presence、URI identity-map、mutable alias、Uint32 buffer 与 ProviderResult turn order。JavaScript prototype、descriptor、Symbol、任意 service decorator 和 source-level cast 仍属于既有 JS runtime/source compatibility cut。

本轮十个确定命中

122 · Swift Array 自动等价Chrome 在 Promise resolution 后仍观察同一 Array 的 queued mutation。mutable T[] 固定为 MainActor reference MonaArray。
123 · Dictionary 可替代 Map<Uri,…>JS Map 对对象按 identity；等 components 的另一个 Uri 不命中。用 ObjectIdentifier，不用 URI 值相等。
124 · 所有 URI map 都按 identityMonaco ResourceMap 明确以 uri.toString() 为 key。public Map 与 internal ResourceMap 保持两套相等性。
125 · Data 可替代 Uint32Arraysemantic-token consumer 保存原 Uint32Array reference，delta 再按 UInt32 index 复制。MonaUInt32Buffer 保留逻辑元素与 alias。
126 · Optional 可同时表达缺失与 nulld.ts 有 205 个显式 null/undefined token。Presence、Nullable、Nullish 三种 canonical 类型分开。
127 · any 全部映射 Swift Any22 个 path 的动态值承担命令、JSON、attachment、view state 与 service override 等不同责任。逐域拆成明确 tagged types。
128 · async provider 不接触 live modelMonaco provider function 先同步收到 live ITextModel 并可重入。direct provider 为 @MainActor；LSP background 才只看 snapshot。
129 · immediate result 可 inline 消费Promise.resolve/await 把结果消费放入 microtask；provider call 本身仍同步。MonaProviderResult 与 MonaMicrotaskQueue 分离两阶段。
130 · Monarch 已完全不可达TokensProviderFactory.create 的 union 仍含 IMonarchLanguage。只裁该 union member，保留 manual/encoded provider factory。
131 · 直接复制 provider result 更安全Monaco Map/Array/Uint32 result 的同 reference 延迟变化可被 consumer 看到。canonical mutable result 不在 completion 时偷偷 snapshot。

Presence 与 dynamic payload

Presence

  • MonaPresence：absent / present
  • MonaNullable：null / value
  • MonaNullish：undefined / null / value
  • 省略参数永远不是显式 null
  • Optional convenience 不得抹掉 source distinction
  • native declaration manifest 逐 field 记录

Dynamic values

  • LSP/serializable state：MonaJSONValue
  • in-process command：MonaCommandValue
  • injected text：MonaOpaqueAttachment
  • service overrides：typed environment
  • inline change hint：JSON only
  • revealFirstDiff：固定 Void

Concurrency

  • mutable canonical containers non-Sendable
  • direct provider 始终 MainActor
  • LSP background 只传 immutable Sendable values
  • 回 MainActor 后 materialize mutable buffer
  • 所有 completion 过完整 validity gate
  • detached task 不得捕获 live container
F1-R4 的唯一处置修正：
555/434/121 路径计数不变。languages.TokensProviderFactory 从 retained-native-mapping 改为 retained-with-explicit-member-cuts；create() 只保留 TokensProvider | EncodedTokensProvider，删除 IMonarchLanguage union member。于是 direct mapping 409→408、member-cut declarations 3→4、显式 member cuts 11→12。其余 disposition 完全不变。
