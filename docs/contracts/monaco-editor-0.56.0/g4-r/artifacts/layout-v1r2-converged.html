布局与渲染收敛版：V1-R2 Core Text 单一排版真相

对抗依据：本地 Monaco Editor 0.56 源码、MacOSX 26.5 SDK 公共头文件、Apple 官方文档，以及本机 macOS 26.6 的 TextKit 2 / Core Text 运行时探针。此版删除了 V1-R 中无法由公共合同证明的 TextKit 分段排版路线。

V1-R2

MonaViewGraph + Core Text 固定为唯一布局链；CoreGraphics 与 Metal 只替换像素生成和合成

ProjectionEngine 精确拥有 model↔view、断行、折叠、注入文本和纵向索引；Core Text 精确拥有每个物化 view row 的 shaping、glyph runs、bidi caret 与 hit-test；Renderer 不得重新排版。TextKit 2 不进入主文本生产链。由此消除逐行双排版、整代排版切换、IME 期间换后端和 TextKit 离屏 estimate 四类状态。

Monaco 同步全量 projectionwrap/config 变化时重建全部 line projections，并同步更新 view-line count prefix sum；这在调用返回后立即可观察。
TextKit 2 离屏不是精确真相Apple 明示其布局始终 noncontiguous；未 ensure 的离屏数据不保证准确，全量 ensure 对大文档代价高。
本机 TextKit 反例clipping 仍换行；maximumLines=1 只截断；break delegate 不能强制外部 break map；裸 line fragment 不产出几何。
本机 Core Text 正例CTTypesetter 按指定 UTF-16 range 生成 CTLine；contextual/cluster break、position↔index、bidi 主/次 caret 均返回有效数据。
Metal 不是 typesetterMetal 只接收 buffer、texture、shader 和 drawable；Unicode shaping 与 font fallback 固定来自同一 CTLine/CTRun 结果。

路线判决

删除

TextKit 2 独占主布局

离屏 estimate 不能进入精确 view graph；全量 ensure 仍无法接收外部 Monaco simple break map。该路线同时破坏同步映射与断行等价。

删除

TextKit viewport row shaper

公共 API 没有“给定 break range 后只 shaping 且永不二次换行”的合同。本机三项探针已经击穿此假设。

锁定

Projection + Core Text + Renderer

断行范围由 Mona 决定，CTTypesetterCreateLine 接收精确 range；所有 renderer 消费同一 LineLayoutRecord，不存在第二套坐标。

坐标、滚动与大文档

固定坐标合同

  • model/view column 均为 UTF-16；validatePosition 禁止 surrogate pair 内部位置，组合序列内部仍是合法 API position
  • 键盘左右移动按 grapheme；pointer hit-test 采用 CTLine index 并归一到合法 UTF-16 boundary
  • bidi record 保存 primary/secondary caret offsets 和 visual caret edges；selection 可生成多个 visual segments
  • 内部横坐标为 Double 逻辑点；纵坐标、scrollTop/Left 和高度为 Int64 整数逻辑点
  • 每帧以当前 scroll origin 做局部坐标减法后才转换 CGFloat/Float，NSView/CALayer/Metal 从不承载巨型 document frame

MonaScrollModel 是唯一滚动真相

  • NSScroller、wheel phase/momentum 与 natural-direction 只是输入/输出适配器，不使用巨型 NSScrollView documentView
  • 精确触控板 delta 保存在 Double residual；公开 scroll position 与 accepted frame 使用整数点
  • rewrap/zone/line-height 变化以首个可见 model position + row delta 恢复 stable viewport
  • 水平 scrollWidth 只取已物化/显式查询 rows 的有效最大宽度，并加 zone/widget minWidth；它不伪装成全文精确值

发散攻击闭环

01 · TextKit estimate 污染 graph

命中并删除：TextKit 2 不再进入主文本布局。

02 · 外部 break map 交给 TextKit

命中并删除：公开 API 与本机探针均未提供此合同。

03 · simple / advanced 混为一谈

收敛：纯算法精确 oracle 与 native typography oracle 分离。

04 · inline font 改写 wrapping

收敛：与 Monaco 一致，只改 row geometry；不改 projection。

05 · 主题一律 paint-only

命中并修正：token bold/italic 进入 GeometryStamp，颜色才是 paint。

06 · backing scale 触发 rewrap

命中并修正：scale 只失效 surface；逻辑 width 不变时 projection 不变。

07 · scrollWidth 伪装全文精确

收敛：明确为 observed width，reveal/query 先物化目标 row。

08 · 巨型 NSScrollView 坐标

收敛：Int64 scroll model + 固定 viewport surface + frame-local origin。

09 · emoji/RTL 逐行换排版器

收敛：全部由 Core Text 排版；renderer 仅混合 mask/RGBA payload。

10 · bidi 单一 caret x

收敛：保存 CTLine primary/secondary offsets 与 visual caret edges。

11 · tab/inlay offset 泄漏

收敛：RenderStringMap 隔离 display UTF-16 与 model UTF-16。

12 · zone 做 attachment

收敛：独立 VerticalWhitespaceIndex；zone 无文本位置。

13 · diff 两侧单独闪动

收敛：两个独立 ViewGraph；paired spacer zones 在同一 presentation batch 安装。

14 · IME/AX 请求离屏 estimate

收敛：QueryGeometryBarrier 同步精确物化，不滚动、不提交临时 frame。

15 · 异步旧结果覆盖新文本

收敛：六类 stamps 全等才安装；迟到结果直接丢弃。

16 · Metal atlas 资源丢失

收敛：renderer generation 切换；完整旧 frame 保留到完整新 frame admission。

17 · 字体安装后缓存失真

收敛：注册字体变化通知递增 resolver/metrics epoch。

18 · 超长行被裁成模型删除

收敛：10,000 只截 paint；model/mapping/commands 全文保留；-1 无内部短上限。

不再属于设计不确定性的三项实测结果

决策规则已经固定

  • CoreGraphics 全指标通过：它取得默认 renderer，Metal 保留为可选加速器
  • CoreGraphics 任一指标落后：Metal 成为交付必需项；Metal 未全过则本节未验收
  • cache 只允许有界 working set；默认 overscan 固定为每侧 max(20 rows, 1 viewport)；任何额外 retention 都计入资源对比

当前事实状态

  • 仓库没有可执行 MonaCode slice
  • 因此没有 renderer 已取得性能通过结论
  • 这不是架构分叉；同一门槛会产生唯一选择
  • 未经实测不写“TextKit/CG/Metal 更快”的结论
