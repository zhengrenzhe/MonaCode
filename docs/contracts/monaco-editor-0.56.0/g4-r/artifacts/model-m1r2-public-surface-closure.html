本轮命中的六个反例

01 · 所有 model API 都同步公开 undo/redo 返回 void 或 Promise。workspace element 还含 confirm 与 prepare 阶段。Swift 固定为 MainActor async；单资源快路径在首次 suspension 前完成。
02 · snapshot 固定 64 KiB 输出PieceTreeSnapshot.read 每次返回当前 piece，首个非空返回值前置 BOM；空树首次返回 BOM，随后 null。chunk 边界是公开可观察值，按 piece 顺序逐次等价。
03 · 字符数就是 grapheme 数非 basic ASCII 路径把 high surrogate 计为一个字符并无条件跳过下一 unit；isolated low surrogate 计一个。逐源码行为保留，不调用 Swift Character.count。
04 · applyEdits 始终逐 operation 执行至少 1000 个 operation 且不存在 tracked op 时，Monaco 合并为一个 operation。touching ranges、排序、EOL normalization 与 trailing CR 也有固定分支。原阈值与分支全部进入 differential。
05 · snapshot chunk 可独立构建 textbuilder 在 chunk 边界暂存 trailing CR 与 high surrogate，等待下一 chunk 决定组合。builder state 跨 read 调用延续，EOF 才结算残留 unit。
06 · 无语言包就删除 language APIITextModel 公开 language id 与两类 language-change event。plaintext 是永远存在的 fallback metadata；provider 缺失只让 provider-dependent action unsupported。
