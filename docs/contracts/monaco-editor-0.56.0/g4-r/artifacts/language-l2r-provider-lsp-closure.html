语言基础设施第四轮攻击：L2-R 唯一合同

全面复刻 Monaco 0.56.0 的 provider registry 与消费语义；LSP 3.18 是标准协议适配层，不替代非 LSP provider，也不提供语言配置。

L2-R

30 个语言表面全部保留；25 个接 LSP；5 个只接 Swift provider

初始发行内置语言定义 0、语言功能包 0、LSP server 0、生产 provider 0。宿主注册 profile/provider 或连接 LSP 后获得对应能力；均未注册时严格退化为纯文本，编辑器功能和文本模型仍可用。

本轮命中的八个反例

01 · 公共 register 函数就是全量monaco.d.ts 有 27 个 register*Provider，其中 1 个是 lexical tokens factory；service 还有 3 个内部 registry。以 29 registry + lexical tokens = 30 为完整表面。
02 · Monaco LSP client 的 22 类就是协议上限其中 Diagnostics 不属于 30 registry，SemanticTokens 同时占 full/range 两面。LSP 3.18 另含 Color、InlineCompletion、LinkedEditing。桥接目标固定为 25 面。
03 · LSP 能提供全部语言行为注释、括号、自动闭合、缩进、Enter、wordPattern、折叠 marker 不由 LSP 提供。MonaLanguageProfile 单独注册；无 profile 时使用通用纯文本行为。
04 · 每个 editor 建立 didOpenMonaco model 可被多个 editor 共享；LSP 文档身份是 URI。ModelSession 对一个 model/session 只发送一次 didOpen；editor 不拥有同步生命周期。
05 · Swift Codable String 足够LSP positionEncoding=UTF-16，JSON 转义可携带孤立 surrogate。沿用 M1-R raw-UTF16 JSON codec；Content-Length 按最终 UTF-8 byte count。
06 · 启动 server 属于组件自动查 PATH、下载 binary 会引入文件系统、网络与签名策略。宿主显式提供 stdio process descriptor、in-memory transport 或 MonaMessageTransport。
07 · provider 返回即生命周期结束completion、code action、code lens、inlay hint 等含 resolve/release；旧 async 结果会越过模型版本。每项结果携带 epoch/version/release token，经 R1 gate 后提交。
08 · selector 只比较 languageIdMonaco 还比较 scheme、pattern、notebook，支持 exact/wildcard、exclusive、built-in 和注册时间排序。逐分支移植 score 与 ordered groups。

经源码计数后的固定表面

生命周期、传输与安全政策

Registry 等价

  • selector：language、scheme、pattern、notebook
  • exact=10、wildcard=5；exclusive=1000 并压制其余
  • 同分：非 built-in 优先；后注册优先
  • register/dispose 立即触发 onDidChange
  • provider fault 隔离为 typed failure，不污染 model

LSP session

  • 版本固定 LSP 3.18；只广告 UTF-16 positionEncoding
  • 支持 initialize/shutdown/exit、dynamic registration、progress、cancel、refresh
  • diagnostics 独立于 30 registry，但进入 marker consumer
  • workspace/applyEdit 只调用宿主授权的 R1 transaction
  • server restart 增加 epoch，旧响应全部失效

Native resource policy

  • header 上限 8 KiB；body 默认 64 MiB、硬上限 256 MiB
  • JSON nesting 128；同时 pending requests 4,096
  • 超限关闭该 session 并返回 typed protocol error
  • Markdown HTML 默认禁用；command/URI link 必须经宿主 opener 批准
  • 组件不下载、不发现、不更新 LSP binary

LanguageProfile 与纯文本降级

MonaLanguageProfile

  • comments、brackets、colorized bracket pairs
  • wordPattern、indentationRules、onEnterRules
  • autoClosingPairs、surroundingPairs、autoCloseBefore
  • folding markers；所有 regex 使用 M1-R ECMAScript runtime
  • registration 可 dispose；变更使相关缓存失效

无 profile、有 LSP

  • 25 个协议映射照常生效
  • 结构编辑使用通用纯文本规则
  • 不猜测注释、括号、缩进或折叠 marker
  • server semantic tokens 不等于 lexical tokenizer
  • 基础 find、selection、multicursor、diff 仍可用

无 profile/provider/LSP

  • languageId 仍保留为 selector metadata
  • 文本模型、渲染、输入、undo、搜索完整工作
  • provider UI 不展示伪结果
  • 不加载任何语言资源
  • 状态明确定义为 PlainTextCapabilitySet
事实索引：Monaco Editor v0.56.0 `languageFeaturesService` 含 29 个 registry；`monaco.d.ts` 含 27 个 register*Provider，其中 lexical tokens factory 不在该 service；内置 `monaco-lsp-client` 含 22 个 feature adapter class；LSP 3.18 另定义 documentColor、inlineCompletion、linkedEditingRange。初始发行的 0 个语言包属于已确认产品范围，不是运行时缺口。
