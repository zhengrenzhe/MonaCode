运行时边界第十轮攻击：H2-R 全局状态、生命周期与资源闭包

H2-R 不增加功能。它覆盖 H1-R 的两态 model ownership、补全 Monaco standalone 的进程级 registries，并把 M1-R/Q1-R 中模糊的大文件与内存失败条款改成可执行合同。

H2-R

共享状态按 Monaco 保持进程级；editor 状态按实例隔离；model 构造保留三态；大文件使用初始 UTF-16 units 严格边界

全局 singleton 不伪装成 per-editor dependency container。多个 editor 可共享一个 model，但 selection、scroll、focus、fold、context、widgets、layout 与 renderer cache 独立。资源验收只声明可恢复 checkpoint；Swift/OS fatal OOM 明确不在恢复承诺内。

本轮十二个确定命中

88 · model 只有“有/无”两态baseline 区分 omitted、object、null。冻结 implicit-owned、external-borrowed、none 三态。
89 · services 全局，registries 可按 editormodel、marker、theme、language/provider、command/keybinding/menu 与 editor list 同样由 singleton/module registry 持有。全部进程级。
90 · editor 的 theme 只影响自己StandaloneEditor constructor/update 直接调用同一 ThemeService.setTheme。最后一次成功选择更新全部 live editors。
91 · 重复 command ID 覆盖并销毁旧项CommandsRegistry 为每个 ID 保存 linked-list stack。最新项先执行；dispose 后恢复前一项。
92 · 同分 provider 先注册优先LanguageFeatureRegistry 用递增 clock 反向排序。同分时后注册优先；builtin 再降级。
93 · 20/50/256 “MB”是字节判断输入是 JS string/model valueLength。单位固定为初始 UTF-16 code units，不是序列化 bytes。
94 · 大文件 flag 随编辑重算三项只在 TextModel constructor 赋值。后续跨阈值增长或缩小均不改变 flag。
95 · 关闭 largeFileOptimizations 会清除三项50 Mi sync flag 在优化分支之外计算。只强制关闭 tokenization 与 heap flag；sync 仍生效。
96 · 100 Mi-unit 性能样本覆盖阈值语义单一大样本不测边界、sticky 或 false 分支。T−1/T/T+1 全部进入 correctness。
97 · allocator denial 等于真实 OOM 可恢复Swift/OS fatal OOM 没有通用恢复通道。只验 test-SPI 的 pre-publication fallible checkpoints；禁止扩大结论。
98 · “有界 cache”可直接验收没有 ID、owner、bound 与 counter 就无法判断 plateau。每个 candidate 必须生成 cache manifest，并与 linked registry set-equal。
99 · 没有实体 numpad 就删除 mapping gate当前 HID service list 无外接键盘，输入源含 ABC 与简体拼音。numpad 用合成 NSEvent 做硬 gate；实体 HID 只覆盖 run manifest 中设备。

Code editor 初始 model 三态

implicitOwned · model omitted由 value 或空 raw UTF-16 创建 process-registered model，选择/推断 language，editor 拥有；首次 detach、replace 或 editor dispose 时处置。
externalBorrowed · model object挂载精确引用；construction value/language 不创建 model；replace/dispose 只 detach，绝不处置外部 model。
none · explicit null不创建、不挂载；construction value/language 不创建 model；之后仅通过 mapped setModel 挂载 borrowed model。

资源与失败边界

Semantic state

  • model、undo、decorations、markers、view state 不是 cache
  • registrations 由 caller disposable/model lifetime 管理
  • memory pressure 不丢 state
  • prepared commit 与 presented frame 不被驱逐
  • 外部 LSP process/transport 属于 host

MonaCacheManifest

  • 每个 strong derived cache 有稳定 ID
  • 记录 owner/key/max entries 或 bytes
  • 记录 eviction/epochs/pressure action/counter
  • linked registry 与 JSON ID set-equal
  • 固定 corpus 100 cycles 不越 bound

Failure claim

  • SPI 在 mutation/publication 前拒绝 fallible request
  • throwing/async API 返回 typed resource failure
  • 同步无错误通道 API 保持 pre-call state
  • test observer 记录拒绝点
  • fatal OOM 不属于可恢复结论
