G1-R

设计分支已清零；实现与实测状态仍为零通过

本期产品是 arm64 macOS 26.0+ 的原生 Swift 编辑器组件，以 Monaco Editor 0.56.0 的可观察能力为基线。文本模型全面等价；布局由自研 Projection + Core Text 掌权；CG 首先实现并接受同一严格性能门槛，只有 CG 任一指标失败才实现 Metal；语言基础设施全量保留，首发语言包为 0；性能每项不得劣于固定 Monaco 基线。

产品范围一次冻结

本期必须交付

  • Swift Package、AppKit editor/diff/multi-diff views、SwiftUI wrapper
  • 同步 ITextModel 等价、完整 editor/core/features/options
  • 自定义 input/IME/AX/clipboard/drag/drop/services
  • provider registry、LSP 3.18 client、host protocols
  • conformance、benchmark、failure-injection 与 sample macOS app

本期 deployment

  • arm64 only；macOS 26.0+
  • Swift 6.3 strict concurrency；Xcode 26.6 / SDK 26.5 baseline
  • 当前 M4 Pro 48 GB 设备验收
  • 60 Hz 外接与 120 Hz 内屏分别通过
  • 生产 runtime 只依赖 Apple system frameworks

长期目标，非本期

  • iOS 26+ / iPadOS 26+ UIKit adapter
  • touch、software keyboard、UIPasteboard/NSItemProvider/UITextDrop
  • 移动端 device matrix 与性能 baseline
  • 核心 Model/Language/Diff/Features 直接复用
  • 移动端未通过不影响 macOS 本期声明

明确排除

  • JS/DOM/WebWorker/NPM/AMD/global API/source compatibility
  • WebGPU/SVG/DOM renderer selector 与 WebGPU texture-atlas debug action
  • Monarch、Tree-sitter、81 个内置语言、4 个内置 language feature packs
  • bundled LSP servers、扩展宿主、Workbench、文件树、SCM、终端
  • AI、协同编辑、非 Apple 平台、x86_64
  • 富文本 model、RTF/RTFD、跨 editor/model drag-move

唯一生产架构

MonaCodeAppKit / SwiftUINSView + NSTextInputClient + NSAccessibility；SwiftUI 只包装。
Features / Diff / MultiDiffcontroller、actions、widgets、zones、state；一个 model 可挂多个 editor。
Projection / Core Text / RendererViewGraph 与 LineLayoutRecord 是几何真相；CG/Metal 只消费 pixels。
Language / LSP / Theme30 provider surfaces、25 LSP mappings、profile、markers、context/keybindings。
MonaCodeModel / Basepersistent raw-UTF16 Piece Tree、undo/events/decorations、URI/cancel/disposable。

不可再打开的决策与仍需取得的事实

架构决策已锁定

  • 无 TextKit production backend
  • 无 editable mirror、无 JS engine、无 third-party runtime
  • 无 runtime renderer selector；CG/Metal 选择只由 Q1 gate 产生
  • 无内置语言包；LSP 仍是 built-in client capability
  • 无 silent no-op；每个 cut 从 Swift type system 删除

实测事实尚未取得

  • MonaCode 代码、测试、sample、benchmark 当前不存在
  • 因此正确性、性能、AX、IME、CG、Metal、LSP、Diff 当前全部未通过
  • 这些状态不是设计分支；实现后用 Q1-R 得到 pass/fail
  • 任一 gate 失败只能修实现或启用既定 Metal 路径，不修改门槛
  • 没有实测数据前禁止对外宣称已等价或不劣

范围变更流程

  • Monaco、Chrome、OS、SDK、设备或 corpus 升级创建新 baseline revision
  • 新增/删除能力先更新 G1-R manifest，再重新分阶段
  • iOS/iPadOS 启动前冻结独立 UIKit/input/AX/performance contract
  • 用户未授权时不添加语言包、AI、协作、workbench 或第三方依赖
  • 所有翻译源码与资源保留 Monaco MIT notice/provenance
G1-R 采纳后的唯一下一步：基于完整范围按依赖图划分实现阶段、里程碑与验收 gate。阶段划分不得删除 G1-R 中的保留能力；每阶段只改变“何时实现”，不改变“最终做什么”。
