运行环境攻击：E1-R 国际化、时钟与熵源闭包

同一份 Monaco 源码同时依赖 UI 语言、浏览器默认 locale、Unicode/ICU 数据、墙上时钟、微任务、帧调度与全局随机序列。E1-R 将这些来源拆开，并为每个可观测点固定 native 语义。

E1-R

UI profile ≠ runtime locale；Chrome 151 的实际 ICU 基线已锁定为 Chromium ICU 78.2

当前机器的 N1 UI 默认仍是 en，运行时 locale 是 zh-CN，时区是 Asia/Shanghai。Chrome 151.0.7922.109 标签锁定 ICU submodule d578f2e；本机 icudtl.dat 为 10,876,560 bytes，SHA-256 9f48c7f9…ebe。产品不链接 ICU runtime，而是生成带完整来源与许可记录的不可变 Swift 表。

四个反例命中

121 · UI 语言等于系统 locale固定 Chrome 中 NLS 默认输出英文，但 Intl 默认 locale 是 zh-CN。两者分离，且都在初始化后不可变。
122 · Swift uppercased 足够ECMA-402 的 locale case 允许实现选择 locale 数据。Foundation 结果不作真值；Chrome 151 是 exact oracle。
123 · RANDOM_HEX 固定六位注入 0.5 的 Chrome 结果是 0.8。先执行 ECMA Number::toString(16)，再取最后 6 个 UTF-16。
124 · timeout 使用 monotonic clock源码 DateTimeout 直接读取 Date.now。语义时钟固定为 wall clock；替换为 monotonic 会改变墙钟跳变结果。

Global entropy

  • 一个 MonaRandomDoubleSource
  • quickSelect 与 suggest sampling 也消耗 draw
  • 无注册 animation 路径不消耗
  • 测试注入精确 binary64 trace

  • 独立 crypto source
  • 16 bytes 注入
  • 强制 v4 与 variant bits
  • canonical lowercase 8-4-4-4-12

Clock queues

  • Date.now / StopWatch(false) = epoch wall ms
  • 13 个 retained StopWatch = mach_absolute_time
  • input latency 同属 high-resolution domain
  • microtask/timer/frame 各保留源顺序

System probes

  • matchMedia → native AX/screen state
  • DOM observers → NSView events
  • RemoteAuthorities 不 rewrite/fetch
  • 无隐式 filesystem/network/process
