原生输入第五轮攻击：I3-R3 composition 与 keybinding 仲裁闭包

本页修正 I3-R2 的全局 resolver-first 错误，并补上 AppKit 菜单 key equivalent 在 view.keyDown 之前消费事件的缺口。I3-R 的双平面、事务、ModelInputBarrier 与 I3-R2 的 key mapping / resolver 排序继续有效。

I3-R3

I3-R2 的“每个 keyDown 都先解析 keybinding”作废；唯一规则改为 composition-aware exclusive arbitration

有 marked text 时，NSTextInputContext.handleEvent 先取得一次且仅一次的消费权；无 marked text 时，resolver 先取得消费权。任何事件只进入 input system、keybinding command、native menu 三个 sink 中的一个。

本轮四个确定命中

27 · 候选方向键被 cursor command 抢走Monaco 的 cursorLeft / cursorRight 只要求 textInputFocus，没有 !isComposing 条件。浏览器靠输入节点 stopPropagation 隔离，不靠 resolver context。
28 · composition Backspace 被 deleteLeft 抢走deleteLeft 同样只要求 textInputFocus。Monaco textarea 在 currentComposition + Backspace 时显式 stopPropagation。
29 · view.keyDown 不是最早入口AppKit 的 local event monitor 在 NSApplication.sendEvent 分发前运行；menu key equivalent 能直接触发 action。只覆盖 keyDown 会漏掉或双执行 Command 快捷键。
30 · chord 与 IME 可同时存活Monaco 进入 MoreChordsNeeded 后调用 IME.disable，退出时 IME.enable。原生状态机禁止 ChordActive 与 MarkedActive 同时为真。

进程内唯一事件入口

AppKeyEventGateway进程内一个 ref-counted NSEvent local monitor；只处理 key window 中 first responder 属于已注册 editor 的 keyDown
›
Immutable dispatch recordevent identity、editor ID、composition token、context snapshot、semantic chord；同一 NSEvent 只创建一条记录
›
State-dependent arbitrationMarkedActive → input context first；Idle → resolver first；ChordActive → resolver only
›
Exactly one sinkreturn nil＝已消费；return original event＝交还 menu / NSView；NSView 读取 record 后只执行尚未执行的 input fallback

composition / chord 原子状态机

Enter composition

  • 仅 Idle 允许 setMarkedText 建立 MarkedActive
  • 每次 callback 继续走 I3-R PreparedInputCommit
  • handleEvent=true 后不得继续 resolver
  • flagsChanged 不创建 single-modifier candidate
  • insert/unmark/discard 完成后回到 Idle

Enter chord

  • 仅 resolver 的 MoreChordsNeeded 建立 ChordActive
  • 若 inputContext 返回 false 后仍有 marked text，先走 ModelInputBarrier：保留已写入文本并清除 mark
  • 进入后拒绝新的 setMarkedText admission
  • 保持 500 ms polling、elapsed>5000 ms、focus-loss 规则
  • 退出后恢复 inputContext admission

Command during mark

  • inputContext 返回 false 才允许 resolver 命中
  • 纯读取 command 直接运行，不改 mark
  • 任何 model/selection mutation 自动进入既有 ModelInputBarrier
  • barrier 后重新验证 R1 DependencyStamp / ApplyTicket
  • 同一 event 不再进入 native menu

Dispatch ledger

  • key 由 NSEvent object identity + eventNumber + timestamp 构成
  • 只存 immutable snapshot 与阶段 bit，不跨 main-run-loop
  • local monitor、menu action、NSView 共享同一 record
  • 过期 record 在 run-loop 尾部清除并记 fault
  • 所有入口 MainActor，记录内无 await

Hard traces

  • 拼音：方向、上下候选、Backspace、Enter、Escape
  • ABC：Option dead key、组合完成、重复键
  • marked 中 Cmd-C / Cmd-Z / custom Cmd binding
  • marked → first chord → second chord / timeout
  • native menu 与 dynamic override 同 key equivalent
