布局与渲染第七轮攻击：V1-R4 跨引擎合同

V1-R3 的 Projection、Core Text、LineLayoutRecord、CG-first 结构继续生效；本页删除“Chrome 像素几何是 Core Text 数值 oracle”的矛盾，并精确划分等价域与原生适配域。

V1-R4

文本与投影逐结果等价；原生几何以 Core Text 自洽合同验收；CG/Metal 共享同一几何

Monaco 的 Blink 字体栈以 HarfBuzz shaping 生成浏览器几何，MonaCode 以 Core Text 生成原生几何。两者不共享 shaping engine，因此不再要求 advanced wrap rows、caret x、glyph bounds、scroll extent 或像素逐数值一致。

命中的八个矛盾

01 · 同一字体名产生同一 glyph advancesBlink/HarfBuzz 与 Core Text 的 shaping、fallback、rounding 链不同。字体名相同不构成坐标等值证明。
02 · Chrome wrap offset 可当 CT oracleadvanced wrapping 消费各自 shaping 与 line-break context。删除 Chrome break-offset patch table；各自布局内部验不变量。
03 · 放宽几何等于放宽模型model offsets、fold/injected ordering、view mapping 不依赖 glyph advances。这些仍逐 raw UTF-16 unit 差分。
04 · renderer 可重新测字二次测量会让输入、AX 与像素出现三套位置。CG/Metal 只消费同一个 immutable LineLayoutRecord。
05 · 任一性能失败都触发 Metalregex、Piece Tree、LSP 慢与 renderer 无因果关系。只有固定 renderer-owned metric 触发 Metal。
06 · Metal 未实现导致正确性 gate 失败CG-first 合同允许 renderer gate 全部通过后不建设 Metal。CG-only 时 Metal parity 明确记 N/A。
07 · Core Text NULL 时切另一排版引擎第二 backend 会破坏唯一 geometry truth。安装同代 FailedLineRecord；不切 TextKit。
08 · AX 可独立估算字符框独立估算会与 hit-test/caret 脱节。AX range/frame 与 IME firstRect 都查询同一 LineLayoutRecord。

等价域与原生适配域

Exact compatibility domain

  • raw UTF-16 model value、EOL、positions、ranges、versions、events
  • fold、hidden area、injected text/inlay 的 ordering、affinity 与 model↔view mapping
  • scroll/top/line APIs 的状态机、reveal intent、save/restore schema
  • simple wrapping 算法在注入同一 FontInfo 数值时的 break trace
  • options/default/clamp、commands、context keys、widgets/zones lifecycle

Native-adapted geometry domain

  • Core Text font matching、fallback、glyph shaping、typographic metrics
  • advanced wrap break offsets、visual rows、caret x、selection polygons、hit-test
  • pixel rasterization、subpixel phase、scroll extent 与 AX screen frames
  • 相同 API 意图与 Unicode 安全合同；不要求 Chrome 数值相等
  • CG 与 Metal 使用同一 CTLine/run/caret records，并做像素 parity

CG-first 与 Metal 的无歧义状态机

CG release path

  • 先完成 Core Text + Core Graphics 全功能实现
  • 通过 Q1-R2 全套正确性、性能、可靠性
  • 通过后 Metal 状态固定为 N/A
  • 发布物不导出 renderer selector
  • CG 是永久 correctness fallback

Metal trigger set

  • first-present 与 input→present
  • missed presentation、frame CPU time、GPU time
  • renderer energy impact、renderer-owned footprint
  • 仅这些 metric 的 Q1-R2 失败触发 Metal
  • model/search/provider/LSP/Diff compute 失败只修所属子系统

Metal completion

  • Metal 不重做 shaping、wrapping 或 hit-test
  • device/resource fault 下一完整 generation 切 CG
  • built 时 validation findings 必须为 0
  • 增加 CG/Metal parity gate
  • 重跑 Q1-R2 全套并逐项通过后才发布
事实索引：Chromium 官方 Blink text-stack 文档把测量、selection geometry、coordinate/index mapping、painting 和 HarfBuzz shaping 列为其字体栈职责；MonaCode 冻结使用 Apple Core Text 的 CTTypesetter/CTLine。两套 shaping engine 不共享数值输出合同。V1-R4 因此删除 V1-R3 的 `AdvancedCompatibilityPatchTable` 与 Chrome exact break-offset oracle；V1-R3 其余 raw UTF-16、DependencyStamp、bounded failure、tile/cache 约束继续生效。
