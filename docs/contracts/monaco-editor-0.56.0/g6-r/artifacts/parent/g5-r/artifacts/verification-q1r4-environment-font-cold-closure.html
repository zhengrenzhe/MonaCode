P00 cold resource protocol 修正版

Active batch

  • 每个有效 block 连续完成 50 次 cold launch
  • 每次 fresh profile + new process tree
  • launch→ready 单独记录 latency；ready 后正常 terminate
  • process tree 全退出后才进入下一次
  • powermetrics 只积分完整 1 秒 intervals

Matched baselines

  • active batch 完成后冻结其 wall-clock event schedule
  • own empty-host 与 neutral idle 分别重放相同总时长/间隔
  • total/component integrals 减对应 baseline
  • 结果除以 50 得 per-cold-launch unit cost
  • 三产品顺序继续按 Q1-R2 Latin balance

No absolute product timeout

  • 删除 3 秒 ready gate
  • 外部 abort 只把 block 标为 invalid，不判某产品性能失败
  • required valid blocks 未凑齐则全局不能 pass
  • P00 latency 仍按 Q1-R3 cell 比较上界
  • 挂起实现无法形成发布 verdict
