布局与渲染最终收敛：V1-R3 可执行合同

V1-R3 继承 V1-R2 的 Core Text 单一排版真相，并纳入 Monaco 0.56 源码、Apple SDK、Unicode/CSS 标准与本机探针命中的全部反例。V1-R2 及更早章节中的 TextKit 生产路径不再是实施依据。

V1-R3

同步 ViewGraph、Core Text 单一 geometry、依赖戳驱动的 CG/Metal 像素管线

Model edit、fold/injected text、wrap/config 与派生 layoutInfo 在同步 API 返回前完成 ViewGraph 和纵向索引提交；后台只计算可丢弃的 LineLayoutRecord 与 surface。任何 renderer、IME、AX、pointer、widget 均不得建立第二套字符或坐标真相。

第二轮命中并修正的反例

01 · 纵向 Int64 全域Monaco custom line-height 是 multiplier × base height，可产生小数。改为 Double prefix sums；仅 public scroll/dimensions 取整数。
02 · projection 后台安装Monaco setWrappingSettings 在返回前同步重建全部 projections。ViewGraph live root 固定 MainActor 同步更新。
03 · AX 只切 advancedMonaco accessibility 同时强制 advanced 与 wrappingIndent=None。两项 computed option 一起移植。
04 · 一个 RenderStringMapsimple 在注入后、tab 展开前断行；advanced 在 tab/control 转换后测量。拆为 ProjectedLineMap 与 TypesetterStringMap。
05 · Swift String 作为真相Swift String 修复非法 UTF-16；Monaco model 可保留孤立 surrogate。raw UInt16/CFString 是边界真相，禁止 Swift String 往返。
06 · Core Text 永不失败Apple 明示 bounded typesetter 对“unreasonable effort”输入返回 NULL。不启用 unbounded；安装 FailedLineRecord，永不损坏 model。
07 · RTL 只靠自然 bidiMonaco 对含 RTL token 使用 unicode-bidi:isolate，对整行支持强制方向。Typesetter map 注入 LRI/RLI/PDI；paragraph style 固定 base direction。
08 · overscan 证据错位max(20, 一屏) 属于 semantic token/inlay request window；DOM 文本层只保留 rendered viewport。两种窗口彻底分离。
09 · 整帧禁止平面复用selection/caret 的 paint-only 更新不要求文字重栅格。每个 plane 独立 dependency stamp；只复用戳仍相等的 surface。
10 · minimap/layout 无环Monaco 注释并实现了 minimap fit/fill 与 viewport wrap 的反馈环稳定记忆。逐语句移植 layoutInfo memory，不另造固定点算法。
11 · AX 任意范围全量 shapingAppKit NSTextView 对全文 frame 返回饱和 canvas rect；精确小范围查询才给紧边界。阈值取 accessibilityPageSize；大范围返回 AppKit-compatible saturated frame。
12 · Atlas 只写 LRU直接逐出会令 in-flight frame 引用已复用页。页带 generation；当前/下一帧 pin；全 pin 时改用有界 RGBA transient tile。
13 · 键盘按最新 UAX29Monaco 0.56 使用自带 GraphemeIterator、生成表与特定 GB11/GB12 简化，不等于 Unicode 17 默认实现。光标与删除逐句、逐表移植 Monaco，不调用系统分词代替。
14 · advanced 无固定 oracleMonaco advanced 把换行交给浏览器 DOM；不同浏览器版本不是同一算法。V1 兼容 oracle 固定为本机 Chrome 151.0.7922.109 + Monaco 0.56.0。
15 · ratio 遇到零基线missed presentation 等计数可在 Monaco 中为零，此时比值无定义。基线为零时要求 Mona 全部有效样本也为零；不做除法。
16 · 失败后切 layout backend生产排版已经只有 Core Text，不再存在 TextKit fallback。CT NULL 安装 FailedLineRecord；只有 renderer device/resource failure 才整代切 CG。

数值、layoutInfo 与失效域

纵向数值

  • line/custom-height 与 vertical prefix sums：Double logical points
  • zone height/minWidth：按 Monaco `|0` 规则截断
  • scrollTop/Left、content dimensions：整数逻辑点；trackpad Double residual 留在输入适配器
  • frame-local origin 后再转 CGFloat/Float

派生布局

  • 逐语句移植 glyph margin、line numbers、decorations、minimap、scrollbar、viewportColumn 与 wrappingColumn
  • accessibility：advanced + wrappingIndent none；long-line dominated 分支照搬
  • minimap fit/fill 的 stable memory 照搬，禁止另起 feedback loop
  • contentWidth 变化同步触发 projection

字体与方向

  • 默认 Menlo/Monaco/Courier New/monospace、12、normal、letterSpacing 0
  • CSS family/weight/feature/variation grammar 形成规范化 FontDescriptorKey
  • base metrics 进入 projection；inline/token typography 只进 geometry
  • font registration、base direction、locale、scale/color space 分别进入对应 epoch

Observed width

  • vertical line↔Y/scrollHeight 全文精确；horizontal scrollWidth 明确为已观测值
  • ViewLines max-width reset/grow 事件逐句移植；数字 max 可在 surface eviction 后保留
  • reveal/query 先物化目标 row，再更新 width 与 scroll
  • zones、overlay widgets 和 scrollBeyondLastColumn 进入原公式

Plane dependencies

  • Projection、Vertical、ScrollDimension、Geometry、Paint、Surface、Frame 分域
  • 每个 line tile/plane 写入实际依赖 key
  • paint-only selection/caret 可复用 geometry/text surface
  • model/geometry 变化后，旧文字与新 cursor 不得组成 accepted frame

Long line

  • 10,000 默认只截 paint；model/projection/commands/copy 保留全文
  • cutoff typesetter input 与 Monaco 同范围，不读取尾部 shaping context
  • -1 不添加自定义长度上限，仍受 Core Text bounded-work safety contract
  • 横向 surface 始终按 viewport tile，不创建整行位图

IME / AX 查询、失败恢复与资源生命周期

QueryGeometryBarrier

  • NSTextInputClient 与 AX 共用 LF-normalized NativeTextIndex；不含 injected/faux/bidi-control 字符
  • IME firstRect 返回第一个可见 logical segment；active selection 落入 fold 时，selection mutation 同步展开后再通知 input context
  • AX 查询覆盖的 model lines 不超过 computed accessibilityPageSize 时同步物化并返回 tight enclosing rect
  • 超过 accessibilityPageSize 时返回 exact vertical extent + 10,000,000-point horizontal saturation 的 AppKit-compatible frame；这是非 tight 的平台饱和几何，stopRenderingLineAfter 之外统一报告 outsideRenderedLine
  • hidden-only AX range 返回 NSZeroRect；跨 hidden/visible range 只 union 可见 segments；query records 在 callback 结束后释放，不提交 frame、不滚动、不进入长期 cache

Core Text bounded failure

  • 固定使用 kCTTypesetterOptionAllowUnboundedLayout=false；不自动重试 unbounded
  • 返回 NULL 时安装同代 FailedLineRecord：固定 row height、诊断 surface、start/end hit zones、outsideRenderedLine geometry
  • model、selection、copy、undo、LSP 与 projection 保持完整；不安装半个 CTLine batch
  • 常规 Unicode corpus 出现 FailedLineRecord：正确性验收失败；专门的 unreasonable-effort corpus 以无 hang/crash/model loss 为通过条件
  • Metal device/resource failure 在下一完整 renderer generation 切 CG；fault frame 不混 renderer generation
