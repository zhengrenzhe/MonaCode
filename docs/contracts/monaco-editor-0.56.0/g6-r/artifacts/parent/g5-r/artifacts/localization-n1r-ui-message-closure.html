功能面补漏攻击：N1-R UI 本地化闭包

代码语言包仍为 0；本页处理的是 Monaco 自身的 action、menu、widget、错误与无障碍文案。它是可观察 UI 能力，不属于 tokenizer、provider 或 LSP 内容。

N1-R

保留官方全部 UI locale profile；默认 English，初始化后不可变

最终 core 产物包含 2120 个有序 message key、13 个 locale 文件和 pseudo transform。MonaCode 全部保留，使用显式 MonaCodeEnvironment localization profile；不调用系统本地化、不联网、不在 editor 存活期切换。

固定产物事实

2120message keys180 个 source modules；English fallback 全量存在。
13packaged localescs/de/es/fr/it/ja/ko/pl/pt-br/ru/tr/zh-cn/zh-tw。
12fully translated每份 2120 个 string。
2120pt-br nulls该官方文件全部回退 English，不伪造翻译。
15selectable profilesEnglish + 13 packaged + pseudo。

四个攻击命中

109 · 语言包为 0 等于无本地化官方 NLS 与代码语言 provider 是两套产物。UI locale 全保留；代码语言实现仍为 0。
110 · 跟随系统 locale 即等价Monaco locale 在 bootstrap 前显式注入。环境初始化显式选择；默认 en；不支持的 ID typed reject。
111 · Foundation format 可替代Monaco 的替换规则、参数类型与 {10} 行为自定义。raw UTF-16 逐规则移植，不用 String(format:)。
112 · pt-br 是完整葡语固定文件实测 2120 项全部 null。保留 profile 与逐项 English fallback，不虚构文案。
