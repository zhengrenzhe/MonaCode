原生边界攻击：H1-R Package、宿主与 SwiftUI 闭包

本页不增加 Monaco 功能，只把已承诺的 Swift Package、AppKit views、SwiftUI wrapper、LSP transport、workspace edit、command/log host 与 multi-diff data source 转成可实现、可编译、可失败注入的合同。

H1-R

三项产品、三种 AppKit view、四个 SwiftUI 类型、七组宿主协议与四态 WorkspaceEdit 已全部冻结

产品面只有 MonaCode、MonaCodeAppKit、MonaCodeSwiftUI。内部模块不成为额外 implementation products；UIKit target 本期完全不存在。SwiftUI 不复制文本或 view state；宿主不获得 open-model mutation 权；LSP transport 不解析协议；transactional capability 只有在 host prepare 产出不可失败 commit 时才能广告。

本轮八个确定命中

80 · 写 Swift Package 即边界完整旧页列了 11 个模块却未区分 products、implementation targets 与 test targets。本期 public products 固定为 3。
81 · SwiftUI 只包装无需合同model identity、dismantle、controller 与重建会决定 model copy 和 double-dispose。四个 wrapper/controller 类型逐项冻结。
82 · 每个 editor 注入 servicesMonaco StandaloneServices 只允许首次 initialize 覆盖；create 的 override 不是 per-editor scope。MonaCodeEnvironment 同样 first-access freeze。
83 · Workspace host 一个 apply 方法足够transactional 要求所有操作全成或全不成；逐操作 async apply 无法实现。另设 prepare + nonthrowing commit。
84 · textOnlyTransactional 只影响文本部分LSP 定义：只要含 resource op，整次 edit 使用 abort。按完整 ordered edit 切换策略。
85 · LSP transport 可以顺便 parseL2-R2/R3 已固定 byte/frame/JSON 四层。host transport 只收发有序 bytes 与 backpressure。
86 · MultiDiff any 可自由设计此前只列列表/折叠，未定义稳定 item identity 与 source change。数据源 snapshot、ID、reorder/state preservation 固定。
87 · MainActor 已足够防回调重入host callback 可在 prepare、send、command、open 中同步/异步重入。root swap/event queue 内零 callback；所有异步结果重验 generation。

SwiftPM 产品与依赖方向

MonaCodeFoundation only；model/editor semantics、providers/LSP、diff/theme 公共面；禁止 AppKit/SwiftUI/UIKit/Metal/CoreText/CoreGraphics imports。
MonaCodeAppKit → MonaCodeNSView、NSTextInputClient、AX、Core Text/CG；Metal 仅在 renderer gate 触发并实现后成为 internal import。
MonaCodeSwiftUI → AppKit + CoreNSViewRepresentable 生命周期桥；无 editable Binding<String>、无第二份 selection/scroll/undo state。

宿主协议的不可跨越边界

Workspace / Command / Log

  • open model mutation 永不委托 host
  • 无 host 时仍支持全 open-model text transaction
  • component command registry 先执行
  • host command 只接 unhandled provider/LSP command
  • log 不含文档正文、不阻塞、不改变控制流

LSP transport / factory

  • ordered byte chunks；single consumer
  • send async throws + backpressure
  • close 幂等；state 有 typed reason
  • factory 明确 owned/remote/embedded ownership
  • 组件不查 PATH、不启进程、不开 socket、不下载

SwiftUI / MultiDiff

  • model/options 更新只走 mapped API
  • controller 只持 weak editor handle
  • dismantle exactly once
  • data source duplicate ID 整批拒绝
  • source identity replacement 使全部 item view state 失效
