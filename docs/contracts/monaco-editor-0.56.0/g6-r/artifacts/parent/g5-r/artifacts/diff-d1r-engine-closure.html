固定 public type 暴露 4 个算法值，但官方 npm 只携带 legacy/advanced 的实现依赖；另外，maxFileSize 不参与计算，DateTimeout 使用 wall clock，缓存源码的真实上限也与注释不同。

D1-R

Legacy 与 Advanced 完整 Swift port；External/WASM 保留枚举值与基线不可用效果

官方 monaco-editor@0.56.0 dependencies 只有 marked 与 dompurify，没有 @vscode/diff。固定 Chrome probe 中 legacy/advanced 各产生一次 update；advanced-external/advanced-wasm 构造成功、update=0，并拒绝 Cannot determine URI for module id!。Native 接受这两个值、不 fallback、不发布新 diff，也不打包 JS/WASM。

四个反例命中

129 · 四个算法都能运行official npm 未声明 @vscode/diff。固定 standalone baseline 下 external/WASM 必然拒绝且无 diff update。
130 · maxFileSize=50 MB gate全源码只有 4 次配置/校验出现，compute reads=0。不能给 native 添加 50 MB 拒绝或截断。
131 · cache 最大 10代码先判断 size>10，再 insert。size=10 时会直接插入第 11 项；硬上限是 11。
132 · timeout 用 monotonicadvanced 与 legacy 都直接读取 Date.now。E1 注入 wall-clock jumps，严格比较 elapsed < limit。

异步执行仍需保持 source order

Snapshot lane

  • MainActor 捕获两侧 immutable snapshot
  • 每 diff editor 一个串行 compute lane
  • 不同 editor 可并行
  • 返回 MainActor 后完整 validity gate

Edit during compute

  • 现有 diff 可同步 transform
  • isDiffUpToDate=false
  • full recompute debounce=200 ms
  • 计算期间 edits 按 source order 补到 result

Process cache

  • key=original/modified URI pair
  • context=model IDs + alt versions + options
  • insertion-order eviction
  • dispose 不主动 invalidation；context 防 stale hit

P10 hard gate

  • 1/10/50 MiU16
  • 1/10/30% changes
  • legacy + advanced
  • compute/CPU/peak footprint 对 M0/M1 均不得更差
