主题基础设施第一轮攻击：T1-R color/token/icon 闭包

F1-R 保留 defineTheme、setTheme、setColorMap、theme features 与 Codicon 资源，但没有固定 registry identity。本页把主题从“功能名称”收敛为机器可核对 artifact。

T1-R

431 个 color IDs、776 个 product icon IDs、4 个 builtin themes 全部保留

CSS 输出本身不属于 native source compatibility；颜色解析、默认值解析、token-rule 匹配、icon ID→glyph、主题切换状态与所有 feature 对 color/icon ID 的引用属于 exact domain。最终像素进入 V1-R4/T1-R native rendering domain。

本轮四个命中

27 · 四个 theme 名称就是完整主题范围feature imports 还注册数百 color/icon identifiers。431/776 registry manifests 同时验收。
28 · NSColor 直接读取 hex 就完成等价Monaco color defaults 含透明度、lighten/darken、oneOf 与主题依赖。先复制 RGBA transform/default graph，再构造 extended-sRGB CGColor。
29 · token rules 只按完整 token 字符串匹配TokenTheme 有 scope hierarchy、rule order、fontStyle 与 encoded color map。移植固定 matcher/metadata packing，不用 NSAttributedString 自己猜优先级。
30 · TTF 文件足够同一 glyph 有 alias ID，feature icon 还可引用另一 ThemeIcon。保留 776 ID graph 与 resolved glyph mapping；TTF hash 只是第二个 gate。
