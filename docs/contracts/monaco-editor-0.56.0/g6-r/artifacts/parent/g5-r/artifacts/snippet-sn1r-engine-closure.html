片段攻击：SN1-R 语法、变量与多光标闭包

片段不是“completion insertText 的一个字符串”。固定源码包含完整 TextMate 风格语法树、变量解析链、RegExp transform、镜像 placeholder、choice、嵌套 session、剪贴板分发、时间快照和全局熵序列。

SN1-R

保留完整片段引擎；仍然不打包任何语言 snippet catalog

Swift port 固定 11 个 parser classes、15 个 token types、39 个 known variables、7 个 format shorthands 和 4 个 session commands。片段文本由 direct provider、LSP completion 或现有 editor API 提供；当前 release 的内置语言实现与内置片段内容仍为 0。

四个反例命中

125 · 只支持 $1 和 $0源码还含 choices、variable defaults、placeholder/variable transforms、if/else format 与 malformed fallback。完整 grammar 全保留。
126 · 多光标共享时间普通 selection insert 每个 cursor 构造 TimeBasedVariableResolver。每 cursor 独立 Date；batch edit 才共享一个 Date。
127 · cursor index 等于排序序号源码按 range 排序处理，却携带原始 idx。CURSOR_INDEX/NUMBER 永远来自调用方原始顺序。
128 · random resolver 可局部注入quickSelect、snippet 与 suggest sampling 共用 Math.random 序列。E1 的 process-global draw order 是 differential 输入。

两个批处理路径不可合并

Selection insert

  • range-sorted processing
  • original cursor idx retained
  • Model resolver shared
  • Time/Workspace/Random 每 cursor 新建

Snippet edit array

  • range-sorted fragments
  • original caller idx retained
  • Model/Time/Workspace/Random 全批共享
  • 只 resolve 新 fragment 与 backfill clones

Session

  • next / previous / leave / accept
  • 同 index mirror 同步
  • nested session 与 undo/redo 保留
  • generation invalidation 清 decorations

Boundary

  • parser/resolver 不直接改 model
  • transaction gateway atomic apply
  • I4 clipboard pre-read
  • 无 filesystem/network/new host API
