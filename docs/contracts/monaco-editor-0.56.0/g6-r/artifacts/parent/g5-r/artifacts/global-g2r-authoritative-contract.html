MonaCode 全量目标：G2-R 最终权威合同

本页冻结最终功能范围、生产架构、等价边界与验收定义。它不声称已有实现；旧页与本页冲突时全部失效。

G2-R

设计选择已收敛为唯一合同；代码与实测仍是零通过

本期交付 arm64 macOS 26.0+ 原生 Swift 编辑器组件。文本模型按 Monaco 0.56.0 逐可观察结果等价；布局使用 Projection + Core Text；CG-first，只有 renderer-owned gate 失败才建设 Metal；语言 registry 全量、LSP client 内置、生产语言内容为 0；性能必须同时不劣于官方原版 M0 与能力匹配 M1。

产品范围一次冻结

本期必须交付

  • Swift Package、AppKit editor/diff/multi-diff、SwiftUI wrapper
  • 同步 ITextModel 等价、完整 core/editor/features/options
  • 自定义 IME/input/AX/clipboard/drag/drop/services
  • 30 provider surfaces、LSP 3.18 client、host protocols
  • sample、conformance、benchmark、failure injection

本期 deployment

  • arm64 only；macOS 26.0+
  • Swift 6.3 strict concurrency；Xcode 26.6 / SDK 26.5 baseline
  • M4 Pro 48 GB 当前设备验收
  • 60 Hz 外接与 120 Hz 内屏分别通过
  • 生产 linked code 只依赖 Apple system frameworks 与仓内 MonaCode code；Codicon 是许可资源

长期目标，非本期

  • iOS 26+ / iPadOS 26+ UIKit adapter
  • touch、software keyboard、UIPasteboard/NSItemProvider/UITextDrop
  • 移动端独立 device/performance baseline
  • Model/Language/LSP/Diff/Features 复用
  • LSP 核心只依赖 message transport，不依赖本地进程

明确排除

  • JS/DOM/WebWorker/NPM/AMD/global/source compatibility
  • TextKit production backend、WebGPU/SVG/DOM selector、WebGPU debug action
  • Monarch、Tree-sitter、81 个内置语言、4 个 language feature packs
  • bundled LSP servers、扩展宿主、Workbench、文件树、SCM、终端
  • AI、协作、非 Apple 平台、x86_64、富文本 model

唯一生产架构

AppKit / SwiftUINSView + NSTextInputClient + NSAccessibility；SwiftUI 仅包装。
Features / Diffactions、widgets、zones、state；single/multi Diff；shared model。
Projection / Core TextViewGraph 与 LineLayoutRecord 是唯一 native geometry truth。
Language / LSP / Themeregistry、byte transport、profile、markers、context/keybindings。
Model / Basepersistent raw-UTF16 Piece Tree、undo/events/decorations、URI/cancel。

不再重开的决定与当前证据状态

Architecture locked

  • 无 TextKit production、editable mirror、JS engine、third-party runtime
  • 无 runtime renderer selector；CG-first；Metal trigger 集固定
  • 无内置语言内容；LSP client 属于核心能力
  • 无 silent no-op；cut 从 Swift type system 删除
  • Core Text native geometry 不冒充 Blink numerical equivalence

Empirical status

  • 仓库没有 MonaCode production source、test executable 或 sample
  • M1 output、corpus、controller、collector artifact 不存在
  • 正确性、性能、AX、IME、CG、Metal、LSP、Diff 全部未通过
  • Metal 在 CG renderer gates 全过时记录 N/A
  • 没有全套通过证据时禁止宣称等价或不劣

Change control

  • Monaco、Chrome、OS、SDK、device、corpus 改动创建新 baseline revision
  • 范围变化先改 G2-R manifest，再重做阶段划分
  • iOS/iPadOS 启动前冻结独立 UIKit/input/AX/performance contract
  • 用户未授权时不添加语言包、AI、协作、workbench、第三方依赖
  • Monaco code 保留 MIT provenance；Codicon 图标保留 CC BY 4.0 attribution/license/modification notice
