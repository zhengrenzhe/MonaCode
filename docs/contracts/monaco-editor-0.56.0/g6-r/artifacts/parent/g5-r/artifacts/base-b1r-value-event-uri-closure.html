补齐 M1-R2 与 F1-R2 之间未单列的 12 个基础运行时值，以及 d.ts 中存在、editor.main 运行时中不存在的 worker 类型命名空间。

B1-R

Foundation.URL、Swift String 与普通 observer 都不能充当 Monaco 基础语义的真相

MonaURI 直接移植 Monaco component parser/formatter；Position/Range/Selection 移植源码分支；Emitter 保留同步重入队列；CancellationTokenSource 保留同步取消与取消后下一主队列 turn 回调。Swift 类型系统只删除 JavaScript 动态伪值域，不删除有效编辑器行为。

本轮八个命中

31 · Foundation.URL 可作为 URI 存储Monaco 使用独立 regex、最小 validation、自定义 percent codec、lazy cache 与 stateful toJSON。MonaURI components 才是 canonical truth。
32 · URI scheme 严格遵守 RFC prose固定源码 regex 是 ^\w[\w\d+.-]*$；严格模式实际接受 1bad。实现服从源码与 fixtures，不按注释改写。
33 · percent decode 遇错只保留坏 triplet连续 percent run 整体失败后按三字符递归；%F0%9F%92%A9%GG 整段保持 encoded。复制 graceful decoder 的异常边界。
34 · URI JSON 与调用历史无关调用 fsPath/toString 后，toJSON 额外带 fsPath/_sep/external cache。MonaURI 是带锁的引用类型，保留 cache-observable output。
35 · Range 依方法名重写几何含义areIntersecting、areIntersectingOrTouching 与 areOnlyIntersecting 的源码边界并不等于注释直觉。逐分支移植并差分，不从名称推导。
36 · observer list 足以复制 Emitter双监听器重入先排完当前 event；单监听器重入立即嵌套；当前轮新增不收当前 event。保留 UniqueContainer + snapshot-end delivery queue。
37 · cancel 一律异步首次 cancel 对已注册 listener 同步 fire；取消后新 listener 用零延迟 task。区分同步 fire 与下一 MainTurnQueue job。
38 · d.ts 的 worker 是第 20 个运行时 export固定 editor.main 实测 19 keys；worker 只包含三个 TypeScript interfaces，编译后被擦除。作为 Swift 类型域保留，不计 runtime value。
