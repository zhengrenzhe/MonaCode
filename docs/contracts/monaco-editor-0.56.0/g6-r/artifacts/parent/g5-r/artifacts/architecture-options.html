哪一个对象掌握“唯一真实文本”？

三种方案都能显示代码；只有数据所有权不同。点击一个方案。推荐 A，因为它同时满足 Monaco 模型等价和 TextKit 2 优先策略。

A

MonaModel 单一真源

推荐
MonaModel
Piece Tree · Undo · Decorations · UTF-16
↓ 共享存储适配，不复制全文
Custom NSTextContentManager
↓
TextKit 2 Layout + Input + Accessibility
↓ 若基准失败，只替换这一层
Custom TK2 Viewport
CoreText + Metal
模型行为可与 Monaco 做差分测试 TextKit 2 是首选布局后端，但不拥有编辑历史和文档语义；渲染下沉不会改动 Model、LSP 或命令 API。
B

TextKit 2 单一真源

NSTextContentStorage / NSTextStorage
↓ 包装
Monaco-compatible Model API
↓
Commands · LSP · Diff · Providers
↓
TextKit 2 Layout + Input
代码最少，系统集成最直接 TextKit 的存储、Undo、版本、Tracked Range 与 Monaco 不同；无法把 ITextModel 完全等价作为可证明的不变量。
C

双模型镜像

MonaModel
TextKit Storage
↕ 双向编辑同步
Range 映射 · 版本仲裁 · 防回环
↓
TextKit 2 Layout + Input
↓
Commands · LSP · Diff · Providers
两个系统都保持原生数据结构 每次输入都产生同步、映射和一致性成本；复制与竞态直接冲击“性能不得劣于 Monaco”的硬门槛。
模型等价同操作序列逐步对比 Monaco 0.56
渲染可替换TextKit 2 失败时不重写上层
性能非劣无全量复制、无双模型同步热路径
长期跨平台Core 与 AppKit/UIKit 解耦
