文本与语言正则第五轮攻击：M1-R3 多 Unicode 配置闭包

M1-R 只封闭了 find/replace 的 g/u/i/m 搜索路径；本轮依据 Monaco 0.56.0 的 11 个保留 RegExp 字段、实际 consumer 源码、本机 Chrome 151 与固定 Unicode 数据重建完整合同。

M1-R3

一个 Swift-owned ECMAScript 引擎，十条 Monaco 消费配置，六份互不替换的 Unicode 快照

生产包不链接 JavaScriptCore、V8、QuickJS 或 ICU。MonaRegExp 是 MainActor 引用对象，保存 canonical source/flags 与可观察 numeric lastIndex；parser/compiler/executor 直接处理 raw UTF-16。搜索使用 g/u/i/m 固定配置，语言配置接受 d/g/i/m/s/u/v/y 全集。

经源码与浏览器核验后的固定数量

14d.ts RegExp 引用11 保留，3 个 Monarch 引用随既有 cut 删除。
11保留字段word 1、indent 4、fold 2、onEnter 3、linked edit 1。
8Chrome flagsd/g/i/m/s/u/v/y；canonical 顺序 dgimsuvy；u+v 抛 SyntaxError。
10消费配置搜索 1，加语言/provider 的九条 clone/reset/match 配置。
2117Test262 源文件RegExp 1879 + regexp literal 238；每个文件必须有 disposition。

本轮八个确定命中

112 · 所有语言 regex 等同搜索 regex搜索只构造 g/u，并按条件增加 i/m；公开语言字段接受浏览器 RegExp 全状态。拆成十条消费配置。
113 · pattern 字符串足够Monaco 比较 flags、读取 source、复用对象并修改 lastIndex。MonaRegExp 固定为 MainActor reference class。
114 · wordPattern 原样执行非 global 输入会被重编译为 g + i/m/u，明确丢弃 d/s/v/y。连“丢 v 后重新编译失败”也进入等价合同。
115 · 每次 test 都会 resetindent 只重置 global；sticky-only 会跨调用携带 lastIndex；fold-all clone 后跨行不重置。逐 consumer 保留状态机。
116 · 一个最新 Unicode 表即可Monaco grapheme/RTL/emoji 是 14.0；confusable 是 UTS #39 16；Chrome regex 是 UCD 17。六 profile 独立冻结。
117 · invisible 表可随时重生上游 canvas 扫描没有记录 Chromium build 与 serif font set。禁止重生；以 Monaco 内嵌 JSON 与 hash 为规范。
118 · Test262 全跑等于 native 全过Proxy、species、Symbol hooks 与 descriptor 属于 JS object runtime。2117 文件逐项分类；接受域 assertion 必须生成 native vector。
119 · 现有 P08 已覆盖性能旧 P08 只有搜索 /gimu，没有 word/indent/fold 与 s/v/y。保持 P08 ID，补全 compile 和九条语言消费路径。
120 · 150ms 是 regex 单次超时wordHelper 只在外层循环顶部读取 Date.now；一次 exec 内没有 deadline。使用 CLOCK_REALTIME 整数毫秒并允许单次执行越过预算。
121 · 连续时钟比 Date.now 更精确Date.now 是可跳变 wall clock；换成 monotonic 会改变回拨/前跳 trace。生产保留 wall clock；差分测试注入相同采样序列。

标准行为与明确裁剪

保留

  • 全部标准 pattern syntax
  • d/g/i/m/s/u/v/y
  • captures/named/backreference/lookaround
  • Unicode property/set/string properties
  • numeric lastIndex 与 canonical source/flags
  • 十条 Monaco consumer 状态机

裁剪

  • RegExp subclass/species
  • Proxy/accessor/descriptor interception
  • Symbol.match/replace 等 user hook
  • lastIndex 的 object/string/BigInt/Symbol coercion
  • 通用 public JS runtime
  • 通用 public RegExp execution library

Clock / bounded work

  • word helper：CLOCK_REALTIME 整数毫秒
  • 150ms 只在外层循环顶部检查
  • regex exec 内无自定义 deadline
  • 同步 find/replace 无 step cutoff
  • 测试向两端注入相同 clock trace
  • stale async 结果只能在发布前丢弃
